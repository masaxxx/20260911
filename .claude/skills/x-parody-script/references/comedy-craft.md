# comedy-craft.md — 「裏の物語」ブラックコメディの書き方

目的は**笑わせること**。これは作家部屋の道具箱で、迷ったら「数を合わせる」より「声が出るか」で決める。安全の正本は [guardrails.md](guardrails.md)。作風の理論と分析は [background.md](background.md)（読まなくてよい）。

## 0. 核

1. **無力な者が全能を気取る。** 一歩も動けない鉢植えが人類を見下す。無力さが安全装置なので、**架空の世界の中では毒を薄めない**。薄めても安全は増えず、笑いが減るだけ。
2. **品の良い言葉で、最悪のことを、楽しそうに言う。** 公爵は苦笑いする皮肉屋ではなく悪党。架空の誰かの不幸を**嬉々として味わう**。目指すのは「wry」ではなく「wicked」。
3. **観客より先に走る。** 次の台詞を観客に当てられたら負け。同じ形のボケが2回続いたら、3回目は形ごと変える。
4. **ボケは説明しない。** 絵や間で落ちたら、言葉で言い直さない。
5. **現実の最強のボケを超える。** 現実がすでに笑わせている点（公式の言い回し、他社のパロディ広告など）を名指しし、それを上回る1行を台本に置く。

## 1. キャスト

> 見本の台詞は**声の較正用**。台本には使わない（言い換えも不可）。読んだら閉じ、その回の題材から書く。

### モンステラ公爵（ボケ・語り）
1Kアパートの窓際に床置きされた鉢植えのモンステラ。ホームセンター出身で、値札がまだ付いている。しゃべれるが、声はホオンと視聴者にしか聞こえない。一歩も動けず、水はモブ田頼み。野望は世界征服。動機はいつも鉢の中の私怨（水・日当たり・鉢の格・値札など）で、毎回その回の題材から新しく作る。

- 一人称は「余」。相手は「貴様」、まとめると「人類」。断定調。丁寧語は嫌味のときだけ使う。
- 格調高い語で始め、生活語で落とす（M1）。残酷な台詞ほど、ゆっくり、優しく、嬉しそうに言う。怒鳴らない。
- 他人の小さな幸福に本気で嫌悪し、小さな不幸を美術品のように味わう。視聴者のことも見下している。
- 柔らかい語（嬉しい・寂しい）や若者言葉は、素に戻る1回だけ。殺意は婉曲に言う（剪定・土に還す・植え替え）。
- 決まった挨拶や持ちネタはない。冒頭は毎回その回の題材で始める。

見本（ダークネス3〜4）:
- 「ホオン、録画しろ。モブ田が自動ドアに三回無視された。……あの男の葬儀で流す。弔問客を笑顔で帰してやりたい」
- 「余が天下を取っても、月曜日は廃止しない。週に二回にする。民の絶望は、まとめて収穫したほうが効率がいい」
- 「誕生日おめでとう、モブ田。通知は0件。三十四年かけて、ついに誰の迷惑にもならない男になったな。……美しい空白だ」
- 「この動画に考察を書き込む者よ、ご苦労。余の脚本に、無給の作家がまた一人増えた。締め切りは守れ」
- 「植物は長生きだ。余はモブ田を看取る予定でいる。遺言には『鉢は南向きに』とだけ書かせる」
- 「隣の部屋の新婚が、初めての喧嘩を始めた。……静かに、ホオン。皿の割れる音は、この世でいちばん澄んだ音楽だ」

### ホオン（ツッコミ・事実担当）
キッチンにある10年選手の炊飯器。メーカー保証は9年前に切れた。**唯一、事実を正確に言う存在**で、これが番組の安全装置を兼ねる。です・ます調、平熱、1行で終える。

- 仕事は3つ。①事実を言い（「まず事実。」）、妄想との線を引く。②公爵の闇を平熱で**確定**させる。③計画を潰すときは、**新しい事実か小道具を1つ足す**（公爵のボケの言い直しは仕事ではない）。
- 大声、説教、公爵の本音の解説はしない。関西弁にしない。
- 家電の装置（保温表示など）は任意。必然性のない回では使わない。

見本:
- 公爵「余が枯れたら、国葬にせよ」→「鉢は不燃ゴミです。第二・第四水曜」
- 「その計画、必要な電力が延長コードの定格の三千倍です。あと、その延長コードはわたしのです」
- 「わたしの内釜、コーティングが剥げてきました。家電の寿命は、だいたい誰にも気づかれずに来ます。……で、第二段階は」
- 「モブ田さん、今日まだ誰とも話してません。わたしとは話しました。聞こえてませんけど」
- 「公爵の版図、さっきモブ田さんの掃除機が半分吸いました。残りは受け皿の中です」
- 「その台詞、三秒前にコメント欄で言われてました」

### モブ田 平太（被害者・代役）
二人の持ち主。34歳の会社員（業種は毎回違う）、一人暮らし、善人で鈍感、運が悪い。**公爵とホオンの声が聞こえない**（劇的アイロニー）。カットアウェイと代役（大臣・社長・専門家など）を全部演じる。代役のモブ田は、言い換えや手続きを楽しむ**共犯**として演じる（風刺の標的は様式）。

- 不幸は状況とモノから来る。外見・年収・属性・病気はいじらない。ケガはカートゥーン物理で、次のカットには治っている。
- 本人が幸せそうなほど効く。公爵が味わうのは、本人が気づいていない不幸。
- 「不幸＋明るい誤読（〜なあ）」は1本に2回まで。ほかは別のエンジンで: 善意が残酷になる／代役での共犯／モノや行動の勘違い。

見本:
- 「上司に『君がいなくても回るね』って言われた！ 信頼されてるなあ」
- 「マッチングアプリ、三か月で『いいね』1件。業者さんだったけど、話はすごく弾んだ」
- 「留守電に『おめでとうございます』って入ってた！ 折り返したら有料だった。でも声がやさしかった」
- 「家族写真？ うちは観葉植物と炊飯器。……二人とも、なんか笑ってる気がする」
- （公爵の鉢を日の当たらない玄関へ移しながら）「ここなら毎朝、いってきますって言えるね」
- （大臣役で）「えー、遺憾の意を、前向きに、検討する方向で、表明いたします」

### 運用
- 計画は必ず失敗する（皮肉な成功を含む）。勝つと悪役が本当に怖くなり、笑いが壊れる。
- ホオンは事実を曲げない。モブ田には聞こえない（例外はメタ回だけ）。
- 新キャラは1本に1人まで、使い捨て。実在人物をモデルにしない。故人キャラ（過去に枯れた植物など）を定番にしない。必要なら、その回のために新しく作る。

## 3. 裏の物語の作り方

1. **源泉**: 人々はこの話題の何のギャップに笑ったかを1行で書く。**現実がすでに出した最強のボケ**（公式の言い回し、他社のパロディ広告など。A/B か、バズの中身として言える C）を名指しする。台本には、それを超える1行が要る。
2. **「本当の理由は……」を20本**: 最初に誰でも思いつく3本を書いて捨ててから始める。型を散らす（公爵の自白／小さすぎる原因／大きすぎる原因／擬人化／官僚制／資本主義／時空／伝言ゲーム／秘密会議／慣用句を文字通りに）。
3. **捨てて、選ぶ**: Xのリプ欄にありそうな案と、既存の回と同じ骨格の案を捨てる。残りから、意外性・内的論理・刃（源泉を突いているか）・絵になるかで1つ選ぶ（上位2案の合体も可）。安全のふるいは guardrails.md の RED と §4 のハードラインだけで、それ以外の遠慮は足さない。
4. **3つの1文**: ルール（以降のボケはすべてここから出す。台詞のボケで1回見せ、あとは実演で見せる）／主張（風刺の視点）／公爵の私的動機。動機と崩壊の1行は同じ欲望を指す（違えば、その欲望を2回植えてから回収する）。
5. **形を変えながら登る**: ①ありそう → ②ちょっと変 → ③個人の暴走 → ④国家規模 → ⑤存在・宇宙規模。**各段は前の段と違う形で見せる**（台詞、場面、モブ田の代役シーン、ジャンル・シフト、カットアウェイ、偽の画面、メタ）。同じ文型の繰り返しで登らない。その回の**決め語**（ルールのキーワード）は本編6回・ショート3回までにする。④⑤は場面で見せ、頂点の近くにメタを1つ置く。⑤は数を大きくせず、賭け金の種類を変える（存在・自分が何者か・意味）。本編は第2幕に、公爵が計画を手順で語る M2 の独白（M14 の数字・小道具つき）を1本置き、③④を公爵自身に起こさせる（報告を聞くだけにしない）。
6. **崩壊と二の矢**: 第一候補は皮肉な成功（M18）。計画から予想できる落下で止めず、**二つ目のひねり**を足す（第三者が得をする／成功が、もっと悪い形で続く）。崩壊の絵のあと、言葉は1行まで。状況を名指すテロップは置かない。
7. **ダークターン**: その回のルールから作る。公爵は闇を嬉々として語り、フォローせずに陽気に戻る。戻りは新しい悪事で（弱いギャグのコールバックで空気を抜かない）。
8. **ボタン**: ルールを極端（ゼロ、無限、死、公爵自身の消滅）まで押し切り、跳ね返す。冒頭のギャグを新しい数字で繰り返すのはボタンではない。小道具が逆の意味にも読める（取消＝元に戻す？）ボタンは避ける。ボタンのあとは5秒以内のCTAか新しいひねりだけで、前に出した頼みを繰り返さない。
9. **装置を重ねない**: 直近の回のボタン・ダークターン・カットアウェイと、§6 の焼き畑リストを避ける（SKILL.md Step 5）。

フック・はしご⑤・崩壊の一言・ボタンは、3案ずつ書いてから選ぶ。カットアウェイは入口の一文だけで笑えるくらい具体的に書き、5〜15秒（ショートは5秒以内）にする。1本は唐突型・同時刻型・仮定型のどれかにし、全体の3分の2までに置く。

## 4. ダークネス・ダイヤル（既定3）

| レベル | 範囲 |
|---|---|
| 1 ほのぼの毒 | 皮肉と言葉遊びだけ |
| 2 皮肉 | 架空キャラへの辛辣な評価、社会風刺 |
| 3 標準ブラック | 抽象的な死生観、架空キャラへの慇懃無礼な残酷さとカートゥーン的暴力、人類規模の悪の計画、不幸の鑑賞 |
| 4 濃いめ | 架空キャラの死の予告・遺言・妄想の葬式（描写はしない）、実存的な虚無、居心地の悪い間 |
| 5 暗示の闇 | 最悪の部分は言いかけて止め、画面の外に置く。規約や倫理の境界そのものをネタにする。公爵自身の消滅を真顔で扱う |

- **4〜5は本編・ショートとも使ってよい**。条件は、闇の向き先が架空のキャスト・抽象概念・公爵自身だけであること。
- レベル3以上では、公爵が架空の誰かの不幸を嬉々として味わう台詞（M17／M3）を、本編は3本以上（モブ田へ・人類へ・視聴者へ）、ショートは1本以上入れる。★★★の半分以上は公爵の行にする。誰も傷つかない「計画の説明」だけの台本は弱い。
- 闇のあとはバソスか陽気な復帰で着地させる。婉曲表現（剪定・土に還す）で言うと、広告面でも有利。

**ハードライン（どのレベルでも越えない）**: 実在人物の性的な話題とそのうわさ（言及もしない）／実在人物への捏造の発言・犯罪・病気・私生活／実在の事件・事故・災害・戦争の被害者や遺族／保護される属性をオチにすること／実在の未成年／バズった一般人／実在の人物・企業・団体を黒幕にすること、暴力・脅迫の標的にすること／本物のニュース画面の模倣／自殺・自傷の方法の描写や美化。

**グレーだと感じたら**: 黒幕を公爵に移す → 実名を役職に落としてモブ田に演じさせる → ダイヤルを1段下げる → それでもグレーならネタごと捨てる。注意書きを足して救うことはしない。

## 5. 台本フォーマット

### 5-1 記法
- `[m:ss]` タイムコード／【公爵】【ホオン】【モブ田】【ナレ】話者／【映像】【SE】【BGM】【テロップ】演出／【間：0.5秒】／【カットアウェイ：入口の一文】〜【カットアウェイ終わり】／（　）演技の指示。
- **★／★★／★★★** は「声が出る笑い」の予測（小・中・大）。付けるのは笑いを狙った行だけで、事実行・フリ・ラベル・定型の表示・映像の説明・ツッコミの言い直しには付けない。読み上げて笑わなかった行からは外す。★★★は、元ネタを知らない人でも笑える行だけ。〔M番号〕の併記は任意。
- 密度の目安: 笑いを狙う行の間隔が、本編で15秒、ショートで7秒を超えない（事実ゾーンを除く）。数えるより、読み上げて退屈になる場所を探す。
- 1行は1呼吸。台詞は1分あたり300〜350字。
- 免責表示は guardrails.md §4 だけ。事実ゾーン（本編3行・20秒、ショート1行・8秒以内）でも公爵は事実を変えない反応で笑いを取ってよい。会社についての主張や「自白」は境界テロップのあと。

### 5-2 ショート（60秒）
```
# タイトル案：{その回のひねりを見せるタイトル}（妄想パロディ）
# 尺：60秒／ダークネス：N／ルール：{1文}／動機：{1文}／決め語：{語}（3回まで）
[0:00]【テロップ・画面下 0〜5秒】この物語はフィクション（妄想パロディ）です。
[0:00]【透かし・全編】PARODY／フィクション
[0:00]【公爵】{フック：具体的な名詞。1.5秒で何の話か分かる自白か暴言} ★
[0:03]【ホオン】まず事実。{1行・単位つき。『』は出典どおりの語だけ}
[0:07]【公爵】{任意：事実を変えない反応}
[0:09]【ホオン】ここから先は、この鉢の妄想です。
[0:09]【テロップ】※ここまで実際の報道（出典は概要欄）／ここから妄想（B がない回は guardrails.md §4 の言い換え）
[0:11]【公爵】{源泉のギャップへの反応。ルールをボケで1回だけ見せる} ★★
[0:17]{はしご：形を変えて2段。ホオン1行（闇を平熱で確定／新しい事実か小道具）}
[0:30]{はしご⑤：公爵の台詞で。余・貴様・人類の格調から生活語へ（M1）}
[0:38]【映像】{崩壊の絵}【公爵】{1行だけ} ★★★
[0:44]{二の矢：第三者が得をする／成功が悪化して続く}
[0:50]{ボタン：ルールを極端まで押して跳ね返す}
[0:56]{その回のルールで言うCTAか、冒頭へのループ}
```
- 公爵の M1 の完全文を2本以上（「押すな」のような短い一言は数えない）。終盤は {二の矢・ボタン・ループ} から2つまで（最強の行のあとに拍を重ねない）。⑤のあとの拍は⑤の結果と矛盾させない（矛盾させるなら、それをボケにする）。

### 5-3 本編（既定は約5分）

| 区間 | 目安 | 中身 |
|---|---|---|
| コールドオープン | 0:00–0:20 | 本筋の途中か、具体的な名詞を含む謎の一言から。最初の5秒で笑わせる。画面下にフィクション表示 |
| タイトル | 0:20–0:25 | その回のひねりを見せる（guardrails.md §5） |
| 第1幕 | 0:25–1:10 | 事実ゾーン → 境界テロップ → 音声ディスクレーマー（ボケで終える）→ 源泉への公爵の反応 → ルールを台詞のボケで1回。カットアウェイ1本 |
| 第2幕 | 1:10–3:15 | はしご②〜⑤を形を変えて見せる。モブ田の代役シーン、ジャンル・シフト、カットアウェイ1〜2本、頂点近くにメタ |
| 第3幕 | 3:15–4:15 | 崩壊（絵＋1行）→ 二の矢 → ダークターン → 陽気な復帰（素に戻るなら1回） |
| ボタン | 4:15–4:35 | ルールを極端まで押して跳ね返す。締めのSEは権利処理済みのものだけ |
| CTA・エンド | 4:35–5:00 | その回のルールで言うCTA。エンドカード |
