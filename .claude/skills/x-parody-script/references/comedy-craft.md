# コメディ脚本術：「裏の物語」ブラックコメディの書き方

> **位置づけ**：このスキルの心臓部。トピック選定（安全ゲート）を通ったネタを台本にするための技術書。トピックの収集と除外ゲートは [trend-sourcing.md](trend-sourcing.md)、安全・法務の判定（RED / YELLOW / GREEN）とディスクレーマーは [guardrails.md](guardrails.md) で定義している。作風の分析と参考文献は [background.md](background.md)（実行時は読まなくてよい）。
> **読む順**：発想（SKILL Step 5）の前に §0・§2・§3・§4 → 執筆（Step 6）の前に §5 → パンチアップ（Step 7）で §6。§1 のメカニクスは辞書として必要なときに引く。§3-3 の実例は任意。
> **見本の扱い（最重要）**：このファイルの台詞・テロップ・CTA・ダークターン・実例の「本当の理由」は、すべて**型を示す見本**。台本にそのまま、または言い換えて使わない。参照ファイルの例文と**8字以上一致する台詞・テロップは0本**にする。例外は、①定型の表示（冒頭表示・透かし・境界テロップ・エンドカード・概要欄の免責文）、②テンプレートの定型句（「まず事実。」「ここから先は、この鉢の妄想です。」）、③持ちネタ「根も葉もある」の返し1回、④保温カウンターという**装置**（数字と反応の台詞は毎回変える）。

## 0. 30秒で読む要点

1. **笑いの核は「無力な者が全能を気取る」こと**。ひどいことを言っても笑えるのは、言っている本人が窓際の鉢植えだから（良性の違反）。無力さが安全装置なので、**架空の世界の中では毒を遠慮しない**。
2. **品の良い言葉で、最悪のことを、静かに言う**。怒鳴った瞬間、ただの悪口になる。
3. **公爵は解説者ではなく悪党**。私怨（水・日当たり・鉢・値札）で動き、慇懃無礼の刃を部屋の中の相手（モブ田・ホオン・視聴者）に向ける。他人の幸福に本気で嫌悪し、他人の不幸をうっとり眺める。
4. **現実の皮肉を拾う**。そのトレンドで人々が何のギャップに笑ったか（笑いの源泉）を、本編で必ずいじる。現実がすでに出したボケより弱い角度は採らない。
5. **裏の物語の黒幕は必ず架空**（基本は公爵本人）。実在の人物・企業・団体を黒幕にしない。
6. **事実はホオンが短く正確に言い、境界テロップを1回**。免責表示は guardrails.md §5 の決まった場所だけ。**台本の中に注意書きを撒かない。ボケを説明しない。**
7. **型**：事実 → 否定 → 自白 → 計画（エスカレーション）→ 小さな誤算か皮肉な成功で崩壊 → ダークターン → 陽気な復帰 → ボタン（ルールが公爵自身に跳ね返る）。
8. **密度**：本編は15秒、ショートは7秒に★1つ（事実ゾーンは除く）。弱いボケは捨てて、新しく書く。
9. **ダークネスは既定3**。どのレベルでもハードライン（4-4）は越えない。

## 1. 技法編：移植できるメカニクス

参照元は米アニメ『ファミリー・ガイ』のストゥーイ。借りるのは**技法とトーンだけ**（権利の線引きは2-0）。この作品名・キャラ名は、リファレンス内の分析と禁止リストにだけ登場させ、**台本・タイトル・サムネイル・概要欄・タグには出さない**。作風が成立している理由（良性の違反・声と語彙の落差・悪役の脆さ）の分析は background.md §1。

### 1-1 移植できる18のメカニクス

各項目に、日本のお笑い用語で近い概念を併記した。例はすべて本スキルのオリジナルキャラ（2章）で書いた**見本**（流用禁止）。

**M1. バソス（格調から卑近への落差）**　≒「落とし」
- 仕組み：格調高い言葉で持ち上げ、くだらない現実に着地させる。
- 作り方：文の前半に漢語・貴族語、**文末に生活語**を置く。逆順にするとほぼ効かない。
- 例：「余の版図は、この窓枠から電子レンジの裏までである。電子レンジの裏はまだ平定できていない。ホコリの抵抗が激しい」

**M2. 誇大妄想と悪役モノローグ**　≒「キャラボケ」
- 仕組み：目的は世界規模、手段は鉢の中。手順を真顔で説明するほど笑える。
- 作り方：「第一段階、第二段階…」と手順にし、最後の段に致命的に小さい障害を置く。
- 例：「計画は完璧だ。第一段階、全国の水道を掌握する。第二段階、人類を渇かせる。第三段階……誰か余に水をくれ。今週まだ一滴ももらっていない」

**M3. 慇懃無礼な残酷さ（デッドパン）**　≒「毒舌」。ただし声は荒げない
- 仕組み：内容の残酷さと口調の丁寧さのギャップで笑わせる。**作中の相手（モブ田・ホオン・架空の役・視聴者）に向けて言う**。抽象概念に向けた毒は刺さらない。
- 作り方：罵倒語は使わず、「評価」「比喩」「事務的な通告」の形で刺す。ゆっくり、優しく言う。
- 例：「モブ田、貴様の人生を一言で言うなら『試供品』だ。誰も本気では求めていないが、もらえるなら一応もらっておく」

**M4. 誤った優先順位**　≒「そこ!?」
- 仕組み：大惨事のさなかに、些細なことを本気で心配する。
- 例：「人類が滅ぶのは構わん。だが、ポイントカードの期限が今月末なのは困る」

**M5. メタ・第四の壁**　≒「楽屋オチ」
- 仕組み：自分が動画の中にいると知っている。YouTubeでは特に強い。**本編に1回以上**。
- 素材：広告、尺、編集者、テロップ、コメント欄、アルゴリズム、縦画面、切り抜き。
- 例：「この動画が伸びなければ、余の計画はアルゴリズムに阻まれたことになる。つまり余は悪くない」

**M6. カットアウェイ**　≒「回想コント」（詳細は5-4）
- 仕組み：本筋を止め、5〜15秒の独立したスケッチを挟む。戻ったあとは説明しない。

**M7. 唐突な非論理（ノン・シークイター）**　≒「シュール」
- 仕組み：流れと無関係な一言や絵を真顔で挟み、何事もなかったように戻る。**1本に1回まで**。
- 例：「ホオン、第二段階を説明しろ。……いや待て。イルカは寝ているとき、何を考えていると思う？　……よし、第二段階だ」

**M8. エスカレーション**　≒「畳みかけ」（3-2のはしごを参照）
- 仕組み：ボケのたびに規模・被害・公爵の得を一段ずつ上げ、最後に一気に落とす（M1と合わせる）。

**M9. 3の法則と裏切り**　≒「三段オチ」
- 仕組み：2つで型を作り、3つ目でずらす。ずらし方は「スケールを落とす」か「ジャンルを変える」。
- 例：「余が欲しいものは3つ。世界、全人類の服従、そして……ホームセンターで見かけた陶器の鉢（3,980円）」

**M10. コールバック**　≒「天丼」
- 仕組み：前半に置いた種を後半でひねって回収する。1回目で置き、2回目は同じものを出し、3回目でひねる。
- 天丼の数字と反応は毎回変える（例の保温カウンターは「12→38→計測不能」に固定しない）。

**M11. 劇的アイロニー**　≒「志村うしろ」型
- 仕組み：観客だけが知っている状況を作る。モブ田には公爵とホオンの声が聞こえない、という設定がこの装置になる。
- 例：公爵「今夜、貴様を剪定してやる」→ モブ田（葉をなでながら）「今日もツヤツヤだね〜」

**M12. ダークターンから陽気な復帰へ**
- 仕組み：一瞬だけ深い闇を覗かせ、フォローも反省も挟まずに、明るく話題を戻す。切り替えにはSEを入れる。
- **闇はその回のルールから作る**。故人の多肉植物などの定番に逃げない。
- 例（ルール「怒りは電力になる」の回）：「怒りが電気になるなら、悲しみは何になるのだろうな。……誰も測らないから、ただ溜まるだけか。【間】さて！　第三段階だ！」

**M13. 脆さの露呈（素に戻る）**
- 仕組み：鎧が一瞬はがれて本音が出て、すぐ悪役の言葉で着直す。これで悪役が「憎めない」存在になる。**1本に1回まで**。きっかけも台詞も毎回その回の出来事から作る（決まった形にしない）。
- 例：（モブ田が葉を1枚だけ拭いた瞬間、早口で）「え、今の見た？　拭いた？　余を？　……不敬である。残りの6枚も拭け」

**M14. 過剰な具体性**
- 仕組み：抽象より具体、丸い数字より半端な数字、一般名詞より固有の小道具のほうが笑える。
- 例：×「昔ひどい目にあった」　○「モブ田が自販機の下の小銭を取ろうとして、腕が抜けなくなった夜だ」

**M15. ジャンル・シフト**　≒「パロディ」
- 仕組み：同じ内容を、急に別ジャンルの文法で語る。
- 使えるジャンル：大河ドラマ風ナレーション、通販番組風、天気予報風、刑事ドラマの取調室風、記者会見風、言い換え辞典風、自然ドキュメンタリー風。
- 注意：実在番組のタイトル・テーマ曲・ロゴは使わない。借りるのは「文法」だけ。

**M16. 引っ張り（S字カーブ）**
- 仕組み：しつこく続けて「面白い → うざい → また面白い」の段階を通過させる。
- 注意：離脱率と相性が悪い。本編で1回、10秒以内まで。ショートでは使わない。

**M17. 不幸の鑑賞（他人の幸福への嫌悪）**
- 仕組み：他人の小さな幸福に本気で嫌悪し、他人の小さな不幸を美術品のようにうっとり眺める。悪役の価値観が一発で伝わる。
- 対象は架空の登場人物の、状況やモノから来る不幸だけ（4-2）。
- 例：家族が声をそろえて「いただきます」→ 公爵「……見るに堪えん」

**M18. 皮肉な成功**
- 仕組み：計画が**成功した結果**、公爵本人が被害者になる。単なる失敗より強い落下になる。
- 例：「成功だ。人類は眠らなくなった。……そして、余の水やりを忘れるほど忙しくなった」

### 1-2 アメリカ風ブラックと日本の文法の配合

- **ツッコミはボケ3つに1回まで**。全部にツッコむと日本のバラエティ番組になり、ブラックの余韻が消える。残りは流して、視聴者に心の中でツッコませる。
- **テロップツッコミは、新しい角度を足すときだけ使う**（「※してません」「※炊飯器です」など）。直前のボケや前提を説明するテロップ（「※ソーセージの話です」）は使わない。
- **間を殺さない**：残酷なオチの直前に0.5〜1秒の【間】を置く。ジャンプカットで詰めすぎない。
- **大声ツッコミと叩きツッコミは禁止**。ホオンは常に平熱。
- **婉曲で刺す**：「死ね」「殺す」などの直接表現は使わず、「剪定する」「土に還す」「植え替える」と言い換える。このほうが笑えるうえ、広告面でも安全。

## 2. オリジナルキャラクター（既定キャスト）

### 2-0 権利まわりの鉄則

- 借りるのは**技法とトーン**だけ。名前、外見、決め台詞、具体的なプロット、声の物真似、映像や音声の切り抜きは借りない。
- **使用禁止**：
  - 元作品のキャラ名・地名（Stewie、Brian、Lois、Peter、Rupert、Quahogなど）
  - 決め台詞とその直訳（"Victory is mine!"、"What the deuce?"、"Damn you, vile woman!"、"Blast!" など）
  - ラグビーボール型の頭、赤いオーバーオールなどの外見
  - 「天才赤ん坊が母親の殺害を企む」「しゃべる犬と時空を旅する」「クマのぬいぐるみが相棒」といった組み合わせ
  - 日本語吹替版の声の模倣
- **そのため主人公は赤ちゃんにしない**。「無力なのに全能を気取る」という構造だけを、まったく別の器（鉢植え）に移す。
- タイトル、サムネイル、概要欄、タグに元作品名や「〇〇風」を入れない（公式との誤認や商標の問題を避けるため）。
- 日本の著作権法にはパロディを直接認める規定がない。実在のCM、楽曲、ロゴ、番組タイトルを「再現」せず、ジャンルの文法だけを借りる。
- ニュースの「事実」そのものに著作権はないが、記事本文・写真・動画は転載しない。事実は自分の言葉で1行にまとめる。
- 合成音声で声を当てる場合は、各ソフトの利用規約（クレジット表記、商用利用の可否）を確認する。

### 2-1 モンステラ公爵【既定ナレーター／ボケ】

**正式名**：モンステラ・デリシオーサ・ド・マドギワ公爵（通称「公爵」）

| 項目 | 設定 |
|---|---|
| 正体 | 1Kアパートの窓際に床置きされた鉢植えのモンステラ。高さ62cm、葉は7枚（うち1枚は黄ばんでいる）。ホームセンターで1,980円。値札はまだ付いている |
| 見た目 | 葉の一枚に片眼鏡。ペットボトルのキャップを王冠代わりにしている |
| 過去 | 2年前の8月、モブ田に9日間水やりを忘れられた（通称「大渇水」）。以来、人類への復讐を誓っている |
| 野望 | 地球を余の葉で覆い、全人類を**日陰者**にすること |
| 能力 | しゃべれる。ただし声はホオンと視聴者にしか聞こえない。一歩も動けない |
| 弱点 | 水やりはモブ田頼み。ハダニが怖い。直射日光で葉焼けする。冬が苦手。「観葉植物」と呼ばれると怒る |
| 隠れた本音 | 本当は誰かに褒めてほしい（M13 で一瞬だけ漏れる） |

**話し方のルール**

- 一人称は**余**。二人称は、登場人物には「貴様」、視聴者には「視聴者諸君」、まとめて呼ぶときは「人類」。
- 基本は「〜である」「〜だ」の断定。**丁寧語は嫌味を言うときだけ使う**（慇懃無礼モード：「大変恐縮ですが、貴様は誤差です」）。
- 決まり文句の回数制限：「〜であろう」は1本に3回まで。「愚民ども」は1本に1回だけ、切り札として使う。「フハハハ」は禁止（使うなら途中でむせさせる）。
- 若者言葉（「マジで」「〜っす」「草」）は禁止。柔らかい語（「嬉しい」「かわいそう」「寂しい」）も悪役の口では使わない。どちらも**素に戻る瞬間だけ**許す（M13）。
- ルールは「標語」で言わず、貴族語で言う。×「減ったら、『アップ』と呼べ」→ ○「減少は不敬である。以後、上昇と呼べ」。
- 演技：低めの声で余裕を持たせる。**残酷な台詞ほど、ゆっくり優しく言う**。怒鳴らない。
- 持ちネタ（オリジナル）：ホオンに「根も葉もない妄想です」と言われたら、「根も葉もない？　余には根も葉もある」と返す。1本に1回まで。
- **毒の最低量**（ダークネス3以上）は §4-3 を守る。公爵が誰も傷つけずに「計画の説明」だけをしている台本は不合格。

**動機は卑小で私的に**：世界征服の動機は、いつも鉢の中の恨み（水・日当たり・LED・鉢のサイズ・値札・大渇水）。毎回1文で決め、計画の各段がその動機に近づくように書く（3-2）。

**語彙バンク**

- 貴族・悪役の語彙：版図、家臣、下々、謀（はかりごと）、勅命、拝謁を許す、寛大にも、遺憾である、良きにはからえ、不敬である、献上、恩赦、流刑、御前会議
- 植物ダジャレ（1本に2つまで）：根回し、根に持つ、芽を摘む、水を差す、日陰者、肥やし、剪定、植え替え、根も葉もない
- 落差用の生活語：1K、受け皿、値札、ホームセンター、延長コード、半額シール、ポイント2倍デー、置き配、既読スルー、サブスク、Wi-Fiのパスワード、100均、燃えるゴミの日

**口調の見本（流用禁止）**

1. 「視聴者諸君、ごきげんよう。今日も余は窓際から人類を見下ろしている。……正確には見上げている。鉢が床置きなのでな」（バソスと自己訂正）
2. 「ここで広告が入る。余の意思ではない。だが広告費は余の新しい鉢になる。スキップした者は、余の鉢を割った者とみなす」（メタと脅し）
3. 「次に余の水を忘れたら、貴様のスマホの充電を、毎晩きっかり79%で止める。一生だ」（生活的で具体的な脅し）

### 2-2 ホオン【ツッコミ兼「事実担当」】

| 項目 | 設定 |
|---|---|
| 正体 | キッチン台の上の、10年使われている5.5合炊きマイコン炊飯器。メーカー保証は9年前に切れた |
| 性格 | 常識人（常識家電）。疲れている。皮肉は言うが平熱。公爵の唯一の話し相手で、計画の穴を冷静に指摘し、最後はなぜか巻き込まれる |
| 番組上の役割 | **唯一、事実を正確に言う存在**。事実を短く述べ、「ここから先は妄想です」と線を引く。これが番組の安全装置を兼ねる |
| 持ちネタ | 表示パネルの「保温カウンター」。モブ田が中のごはんを忘れるたびに時間が増える（毎回の天丼。数字と反応は毎回変える）。締めは炊き上がりのSE（**オリジナル曲か著作権フリー素材**を使う。実在メーカーのメロディは使わない） |

**話し方のルール**

- 一人称は**わたし**。公爵は「公爵」、モブ田は「モブ田さん」と呼ぶ。
- です・ます調で、短く、平熱。ツッコミは1行で終える。説教しない。
- 関西弁にはしない。公爵の格調と対比させるには、平熱の標準語のほうがドライに効く。
- **仕事は3つ**：①事実を言う、②計画の「小ささ」を暴く1行（本編・ショートとも最低1回）、③公爵の闇を平熱で確定させるかぶせ（例：公爵「余が枯れたら、国葬にせよ」→ ホオン「燃えるゴミは火曜です」）。
- **公爵の本音を言葉で解説しない**（「それ、寂しかっただけですよね」型は不可）。脆さは SE・テロップ・行動で見せる。
- 家電の語彙：保温、予約、早炊き、内釜、おこげ、炊き上がり、メーカー保証、5.5合

**口調の見本（流用禁止）**

## 3. 「裏の物語」の発想法

### 3-1 四つの鉄則

1. **黒幕は架空にする**。真犯人は、①公爵本人、②架空の組織（例：全国駄菓子円卓会議、記憶一時預かり所）、③擬人化したモノや概念、のどれか。実在の人物・企業・団体・国・民族・宗教を黒幕にしない。架空の円卓会議は、出席者が擬人化したモノやモブ田の群れなら使ってよい（実在の企業や、特定できる企業どうしが価格を取り決める絵にはしない）。
2. **固有名詞を隔離する**。実在の固有名詞はホオンの事実行（と境界テロップの媒体名・概要欄）にだけ置く。裏の物語パートでは役職名に落とし、モブ田が演じる。ただし企業・団体の**公の文言**（広告コピー・スローガン・公式声明の一文）は、確認できた一字一句のまま公爵が評論・もじってよい（社名・商品名は外す。guardrails.md §4.2-7）。政治家など個人の発言は要旨で扱う（Y1）。
3. **荒唐無稽さで誤認を防ぐ**。誰が見ても事実と取り違えない飛躍を必ず入れる（犯人が鉢植え、記憶が土になる、など）。「ありそうな陰謀」は、切り抜かれて陰謀論として出回る危険があるので採用しない。公爵が物理的に不可能な方法で奪う・変える（「根で吸った」「言葉に変えた」）のは品質の虚偽ではない（guardrails.md §2 の YELLOW の補足）。
4. **叩く方向は上**。対象は権力、制度、巨大な仕組み、不条理、そして語り手自身。被害者、一般人、弱い立場の人は叩かない。黒幕を架空にしても、**風刺の標的（現実の公的な言動の様式）は免罪しない**。架空の黒幕は、現実の振る舞いの受益者か共犯として描く。

### 3-2 手順（12ステップ）

1. **事実の骨格を1行にする**：誰が／何を／数字（単位つき）。これがホオンの台詞の原型になる。確認できないことは書かない。
2. **表向きの理由を書く**：A/B で確認できた範囲だけ。確認できなければ省く。これが「フリ」になる。
3. **笑いの源泉を1行で書く**：人々はこの話題の**何のギャップ**に笑ったか（例：「品質は変えません」と胸を張りながら、箱だけ大きくした）。現実側がすでに出した最強のボケ（他社のパロディ広告、公式の言い回しなど。A/B で確認できるもの。一般人の投稿は引かない）を1つ挙げる。**この回のゲームはそのギャップを利用するか、裏返す。現実のボケより弱い角度は採らない。** あわせて、題材の手ざわり（いちばん絵になる・音になる・皮肉な細部）を1つ選び、小道具かSEにする（ロゴ・CM音源・パッケージ画像は使わない）。
4. **捨て大喜利**：誰でも最初に思いつくボケ（Xのリプ欄に出ていそうなもの）を3本書いて捨てる。台本は「その先」を書く。
5. **「本当の理由は……」を15〜20本出す**：下の「発想の10の型」のうち8つ以上の型から。質より量を優先し、この段階では検閲しない。**§3-3 の実例の骨格の言い換えは数えない**（宇宙の膨張、縄文の協定、稟議の更新忘れ、コンサルの再定義、サブスク化、未来人の警告、並行世界、記憶の預かり所、など）。題材が値上げ系なら、実例Aのルール「怒り＝電力」は使わない。
6. **採点する**：下の採点表を使う。上位2案を組み合わせると強くなることが多い（例：公爵型×擬人化型）。
7. **安全のふるいにかける**：3-1の鉄則と4-4のハードラインに照らす。NGの案は**直してすり抜けさせず、捨てる**（4-5）。**ふるいはこれだけ。** それ以外の「念のため」の注記や遠慮を足さない（安全はネタ選びと架空化で取れている）。
8. **3つの1文を決める**：
   - **この回のルール（ゲーム）**：例「国民の怒りは電力になる」。以降のボケはすべてこのルールから出す。ルールは**公爵の台詞のボケとして1回だけ**示す。テロップや説明台詞で画面に出さない（ルールは作家部屋の道具で、視聴者向けの字幕ではない）。2回目以降は実演で見せる。
   - **この回の主張（風刺の視点）**：例「企業は値上げのたびに、それを『お客様への感謝』と呼ぶ」。はしごの各段がこの主張を体現する。
   - **公爵の私的動機**：例「育成LEDの電気代をモブ田が払ってくれない」。はしごは、この動機に近づく計画の段階として書く（例の列挙にしない）。
9. **エスカレーションのはしごを組む**：①ありそう → ②ちょっと変 → ③個人の暴走 → ④国家規模 → ⑤宇宙・存在規模 → **落下**。
   - 段が上がるたびに「規模」「被害」「公爵の得」のどれかが上がる。抽象概念を集めるだけの段（「自由の粒を回収」）は不可。
   - 同じ文型（例：「〜が減れば〇〇アップ」）は2回まで。3回目は M9 で裏切る。例の列挙（「卵は7個、餃子は13個…」）は全部で1段と数える。
   - **④⑤は台詞で要約せず、場面かカットアウェイで見せる**。⑤では制度や権威が実害を受けるとよい（例：遺産分割協議が全国で永遠に終わらない）。
   - 頂点の近くにメタ（M5）を1つ：公爵の計画がこの動画自体を脅かす（例：「表現の自由」→「表現の指定」で動画が勝手に終わりかける）。
   - 落下の第一候補は**皮肉な成功**（M18）。次点が鉢植えレベルの小さな誤算（水、コンセント、ハダニ、モブ田）。
10. **「公爵の型」に流し込む**（下記）。
11. **カットアウェイ候補を3〜5本出す**：はしごの各段から作る。同じゲーム（例：公爵がモノとして値踏みされる屈辱）は1本まで。1本は唐突型（M7）か同時刻型・仮定型にする（5-4）。
12. **ボタン（最後の一撃）を先に決める**：第一候補は**この回のルールが公爵自身に跳ね返る形**（計画は必ず失敗する、2-5）。冒頭へのコールバックにひねりを加えられれば最強。公爵が得をして終わるボタンは弱い。オチから逆算して書く。

**フック・はしご⑤・崩壊の一言・ボタン**の4か所は、必ず3案ずつ書いてから選ぶ（6章のパンチアップログに残す）。

### 3-3 実例（題材はすべて架空。任意で読む）

> 実例の「事実」部分はすべて架空。本番では、トピック選定で確認できた事実だけをホオンに言わせる。**実例の商品・集計・流行・「本当の理由」・ルール・台詞を再利用しない**（言い換えも数えない。3-2 の手順5）。

#### 実例A：値上げ ―「国民的駄菓子『ポリ太郎』、42年目の初値上げ」

- **事実の骨格（架空）**：駄菓子「ポリ太郎」が10円から15円になる。理由は原材料と物流費の高騰。Xで「#ポリ太郎ショック」がトレンド入り。
- **笑いの源泉**：5円で国中が本気で怒っている、という釣り合わなさ。

**「本当の理由は……」（型ごとに1本の抜粋）**

1. 【公爵】国民の怒りで発電し、余の育成LEDを点ける計画
2. 【小さすぎる】42年前に価格表へ鉛筆で書いた「10」が、ついに消えかけた
3. 【大きすぎる】ビッグバン以来、宇宙の物価は膨張し続けている
4. 【擬人化】ポリ太郎本人が42年ぶりに賃上げを要求し、春闘に参加した
5. 【官僚制】値上げ申請のハンコが、42年かけてようやく全部そろった
6. 【伝言ゲーム】社長の「5円ずつ上げていこう（士気を）」が誤って伝わった
7. 【秘密会議】全国駄菓子円卓会議で、チョコ派が棒派を追い落とした
8. 【文字通り】「値が張る」→ 袋がパンパンに張った

- **採用**：1番（意外性5・論理4・刃4・絵5・伸びしろ5・身内化5）
- **この回のルール**：「国民の怒りは電力になる」／**主張**：「人は大きな理不尽より、小さな5円に怒る」／**動機**：「育成LEDの電気代をモブ田が払ってくれない」
- **はしご**：①原材料費のせい（ホオン）→ ②値上げを決めたのは余だ → ③目的は5円で生まれる怒りの採取 → ④怒り発電所（絵：ハムスター車輪で怒鳴るモブ田たち）→ ⑤光合成で葉を増やし、地球を日陰にする → **落下（皮肉な成功）**：公爵自身の怒りが、モブ田のスマホを満充電にする
- **ボタン**：公爵「……余が、あの男の充電器に」

→ ショート台本の完成版は5-6にある。

#### 実例B：失言パターン ―「答弁の『記憶にございません』、今年は過去最多（架空の集計）」

- **事実の骨格（架空）**：今国会で「記憶にございません」系の答弁が過去最多。特定の個人ではなく「パターン」を扱う。
- **笑いの源泉**：記憶がないと言う人ほど、答弁の言い回しだけは完璧に覚えている。

**「本当の理由は……」（抜粋）**

1. 【官僚制】永田町に「記憶一時預かり所」があり、都合の悪い記憶はそこに預けている（保管期限3年）
2. 【公爵】消えた記憶は全部、余の鉢の土に埋まっている
3. 【官僚制】記憶の開示には情報公開請求が必要で、出てきても黒塗り
4. 【擬人化】記憶のほうが本人に愛想を尽かして家出した

**採用**：1・3・2を合体させる → 預かり所で保管期限が切れた記憶は廃棄され、園芸用の「腐記憶土（ふきおくど）」として格安で売られる。モブ田がホームセンターの半額コーナーでそれを買い、公爵を植え替える。

- **この回のルール**：「忘れられた記憶は、土になる」
- **はしご**：①答えたくないから（ホオン）→ ②記憶は消えたのではない、預けられたのだ → ③保管期限が切れると、黒塗りのまま廃棄される → ④廃棄先は腐葉土工場。「腐記憶土」としてホームセンターへ → ⑤植え替えられた余の根が、この国のすべてを吸い上げた → **落下**：誰も植物の話を聞かない。モブ田には声が聞こえない
- **代役**：答弁シーンの政治家は全員モブ田（議員バッジとヅラ付き）。テロップ「※登場する政治家は全員モブ田です」（1回だけ）
- **ボタン**：冒頭で公爵が「思い出した……すべてを」と言う → ラストでホオン「で、何を思い出したんですか」→ 公爵「……記憶にございません」（土の"成分"が公爵自身に効いてしまった＝ルールが跳ね返る）

→ 本編のビートシートは5-3の記入例にある。

#### 実例C：バズグルメ ―「『マヨ茶漬け』がXでトレンド入り、一部コンビニでマヨが品薄」（架空）

- **事実の骨格（架空）**：深夜のマヨ茶漬けが「#背徳茶漬け」として急に広まった。
- **採用**：流行の発祥はモブ田の最悪の夜の一杯。マヨをかけた本当の理由は、ホオンの中で長時間保温されていたごはんだった。
- **この回のルール**：「流行の正体は、誰かの最悪の夜の再現である」
- **はしご**：①手軽で背徳的だから（ホオン）→ ②元祖はモブ田。企画書を5回差し戻された夜の一杯 → ③泣きながら投稿したら、朝には10万いいね → ④全国が毎晩「同じ夜」を再現する → ⑤一人の男の最低の夜が国民的行事になる → **ひねり**：真犯人はホオン（公爵「貴様……余より悪役ではないか」）
- **ボタン**：モブ田がXに「マヨ茶漬けの元祖、実は僕なんです」と投稿する →【テロップ】いいね：2 → 公爵「誰も信じない。元祖とは、そういうものだ」
- **注意**：現実のバズの発端が一般人の投稿だった場合、その人は絶対にネタにしない。発端の役は必ずモブ田に差し替える。

## 4. ブラックユーモアの調整

### 4-1 原則：深刻さと「距離」は反比例する

ユーモア研究では、深刻な出来事ほど、笑うためには心理的な距離（時間、空間、仮定、社会的な距離）が必要だとされる。Xのトレンドは**時間的な距離がほぼゼロ**だ。だからこのスキルで扱えるのは**深刻度の低いネタ**だけになる（値上げ、流行、言い回し、珍ニュース、制度の不条理）。深刻なネタは距離を作れないので扱わない。

逆に、距離を作る手段が「架空化」である。黒幕を鉢植えにし、登場人物をモブ田にし、舞台を1Kアパートに移す。現実から一段離れることで、残酷な台詞が「良性」になる。**距離が取れている架空の世界の中では、毒を薄めない**。薄めても安全は増えず、笑いだけが減る。

### 4-2 効く闇と効かない闇

| 効く（ブラックとして笑える） | 効かない（ただ残酷に見える） |
|---|---|
| 抽象的な死・老い・虚無（「いずれ全員、土に還る」） | 実在の事件・事故・災害・戦争と、その被害者 |
| 官僚制、会議、ハンコ、前例主義、言い換え | 実在人物の性的な話題、捏造したスキャンダルや発言 |
| 資本主義、値上げ、KPI、サブスク、ポイント経済 | 人種、民族、国籍、宗教、性別、性的指向、障害、病気、出自 |
| 語り手自身の悪意と無力さ | 一般人、素人、バズった個人 |
| モノ・家電・架空キャラへの不条理な暴力（即復活する） | 外見・貧困・病気をオチにすること |
| 架空キャラの生活の侘しさ（一人暮らし、倹約、報われなさ） | 実在の誰かの私生活 |
| 権力者の「公的な言動パターン」（個人攻撃ではなく型として扱う） | 自殺・自傷の具体的な描写や美化 |
| 人間の普遍的な小ささ（5円で怒る、通知に振り回される） | 子どもや動物への具体的な暴力（植物と家電は可） |

### 4-3 ダークネス・ダイヤル（既定：3）

同じ設定「モブ田が2週間の旅行中、公爵の水やりを忘れた」で、5段階を比べる（例は見本。流用禁止）。

| レベル | 名前 | 範囲 | 例 |
|---|---|---|---|
| 1 | ほのぼの毒 | 皮肉と言葉遊びだけ。死や暴力は出さない | 「おかえり、モブ田。余は少々しおれている。旅のしおりより、しおれている」 |
| 2 | 皮肉 | 架空キャラへの辛辣な評価、社会風刺 | 「2週間か。貴様の有給は、余の命より重いらしい。……正しい判断だ。有給は使わないと消えるからな」 |
| **3** | **標準ブラック（既定）** | 抽象的な死生観、**過去に死んだ架空キャラへの言及**、制度への辛辣さ、架空キャラへの慇懃無礼な残酷さとカートゥーン的暴力、荒唐無稽な規模の悪の計画 | 「この2週間、余は死について考えた。土に還るとは、要するに今いる場所から一歩も動かないことだ。余はもう、ほぼ死んでいるのかもしれん。……おかえり！　土産は水でいいぞ！」 |
| 4 | 濃いめ | 画面内の架空キャラが**これから死ぬ示唆**（遺言・予告・妄想の葬式。描写はしない）、実存的な虚無、居心地の悪い間。本編のみ | 「留守の間に遺言を書いた。財産はすべてホオンに譲る。モブ田、貴様には余の鉢を遺そう。サイズは合わんだろうが、いずれ貴様も、どこかの土に入るのだ」 |
| 5 | 暗示の闇 | 最悪の部分は言いかけて止め、画面の外に置く。規約や倫理の境界そのものをメタにネタにする。本編で1か所まで | 「今夜、貴様が眠ったら、余は根を伸ばし、枕元まで這っていく。そして——」【SE】ピー【テロップ】※ここから先は規約の都合により、公爵の脳内でのみ上映中【公爵】「……まあ、根は30cmしかないのだがな」 |

**毒の最低量（足りなければ第7項目で不合格）**

- **レベル3以上の本編**：①慇懃無礼な残酷台詞（M3）を、作中の相手（モブ田・ホオン・架空の役・視聴者）に**3本以上**、②公爵の悪意に架空の被害者がいる場面を**1つ以上**、③ありえないほど具体的で生活的な脅し（「スマホの充電を毎晩79%で止める」の型）を**1つ以上**、④4-2の「効く闇」の列から**2種以上**。セルフレビューでは該当台詞を引用する。
- **レベル3のショート**：①を1本以上と、③かダークターン1行。
- 公爵の計画が「気まずい朝食」程度の被害で終わるなら、規模が足りない。架空の世界の中で、人類規模の（抽象的な）破滅まで登らせる。

**毒の見本（register の確認用。流用禁止）**

- 慇懃無礼（モブ田の生活へ）：「モブ田、貴様の冷蔵庫を拝見した。調味料が11本、食材が0。……味付けだけで生きている男か。実にふさわしい」
- 視聴者へ：「視聴者諸君、これを無料で見ているな。結構。貴様らの時間は、もともと無料同然だ」
- 不幸の鑑賞（M17）：「見よ、ホオン。モブ田が半額弁当を2つ並べて、どちらを明日に回すか悩んでいる。……これが、余の見たかった文明だ」
- ルールから出たダークターン（ルール「行列は並ぶ者の寿命で進む」の回）：「人生とは、何の店か分からん行列だ。最後尾の札を持たされ、気づけば先頭で、店は閉まっている。【間】……さて！　次の行列だ！」

**運用ルール**

- ショートは**最大3**まで（未成年の視聴者も多いため）。本編は3を基準にし、4はピンポイントで使う。
- **ショートで4〜5を指定されたら**、3に丸めて報告し、3の中で濃度を最大にする：(a) はしご⑤を人類規模の抽象的な破滅にする、(b) ダークターンを1行入れる、(c) ホオンが平熱で闇を確定させるかぶせを入れる、(d) 闇の直後にバソスで着地する。
- ユーザーがレベルを指定したら従う。ただし**ハードライン（4-4）はどのレベルでも変わらない**。
- レベルが上がるほど、直後にバソス（M1）か陽気な復帰（M12）を入れて、必ず「安全」に着地させる。闇のまま終わらせない。
- 暴力的な表現や汚い言葉が多いと広告制限を受けやすい。婉曲表現（「剪定」「土に還す」）で言う。

### 4-4 ハードライン（全レベル共通・例外なし）

- 実在人物の性的な話題。「流出動画」「ディープフェイク」の類の噂は、トレンド上位であっても**題材にもカットアウェイにも使わない。言及もしない**（噂に触れた時点で拡散に加担することになる）。
- 実在人物に、捏造した発言・行動・犯罪・病気・私生活を与えること。
- 実在の事件・事故・災害・戦争の被害者や遺族を笑うこと。
- 保護属性（人種、民族、国籍、宗教、性別、性的指向、障害、病気、出自）をオチにすること。
- 実在の未成年者。
- バズった一般人をいじること（扱うのは現象だけ。人物はモブ田に差し替える）。
- 実在の人物・企業・団体を「黒幕」にする陰謀論仕立て。
- 実在の報道機関のロゴや「速報」テロップを模して、本物のニュースと誤認させる演出。
- 自殺・自傷の方法の描写や美化。

### 4-5 グレーだと感じたときの処理順

1. 黒幕を公爵に移す。
2. 実在の名前を役職に落とし、モブ田に演じさせる。会議の出席者が実在の企業に見えるなら、擬人化したモノに替える。
3. ダイヤルを1段下げる。
4. それでもグレーなら**ネタごと捨てる**。Xのトレンドは毎日いくらでも出てくる（候補リストの次点に戻る）。

※ 注意書きを足して救う、という処理はない（guardrails.md §5 の予算を超える注記は足さない）。

## 5. 台本フォーマット

### 5-1 記法

| 記号 | 意味 |
|---|---|
| `[m:ss]` | 行頭のタイムコード（目安） |
| 【公爵】【ホオン】【モブ田】【ナレ】 | 話者。【ナレ】はジャンル・シフト時に使う別人格のナレーション |
| 【映像】【SE】【BGM】【テロップ】 | 演出の指示 |
| 【間：0.5秒】 | 間。残酷なオチの直前に置く |
| 【カットアウェイ：入口の一文】〜【カットアウェイ終わり】 | 差し込みスケッチ |
| （　） | 演技の指示（例：（急に早口で）） |
| ★／★★／★★★〔M番号〕 | 狙っている笑いの強さ（小・中・大）と、使ったメカニクス。例 `★★〔M3〕` |

**★の付け方（較正）**

- ★は「声が出る笑い」の予測。付けるのは、笑いを狙った行（台詞、またはそれ自体がボケとして成立するテロップ・映像）だけ。
- **付けない行**：事実行、境界テロップ、冒頭表示・透かし・代役テロップ・エンドカード、フリの行、映像の説明、直前のボケを言い直すツッコミ、決まり文句の CTA。
- ★には使ったメカニクス番号を併記する。**番号が書けない★は無効**。
- ★★★は、元ネタを知らない人が読んでも笑える行に限る。同じ真相・同じオチを2回目以降に言う行には付かない（★★★は初出だけ）。本編4〜6個、ショート1〜2個。
- **予測テスト**：直前の行を読んだ人がオチの単語を当てられるなら、1段下げる。
- ★の付いた行は全行の45%以内。半分以上に★があるなら、較正が甘い。

**書き方**

- 1行は1呼吸（読点・句点で切って25字前後）。ホオンの事実行は正確さを優先してよい。
- 文字量の目安は、**台詞だけで1分あたり300〜350字**。
- **免責表示は guardrails.md §5 の「ディスクレーマー予算」だけ**：冒頭0〜5秒の画面下テロップ、全編の透かし「PARODY／フィクション」、境界テロップ1回、代役テロップ（実在の役職をモブ田が演じるときだけ）、音声ディスクレーマー1回、エンドカード。**これ以外の「※架空です」型の注記を足さない。** ★の直後や★★★と同じ画面にも置かない。例外は、それ自体がボケとして成立する※テロップ（本編2回まで。例：「※実在の鉄道会社は、酸素で物事を決めません」）。
- 冒頭表示の文言は guardrails.md §5.2 のもの（本編はフル、ショートは短縮版）。フックの台詞は止めない。
- **事実ゾーン**：ホオンの事実行（本編は3行・20秒以内、ショートは1行・8秒以内）→ 境界テロップ。ここは密度の計算から外す。事実ゾーンの中で公爵が挟んでよいのは、**事実を変えず、何も付け足さない反応**だけ（「……ほう」「（うっとりと）美しい数字だ」）。会社についての主張・原因の「自白」は境界テロップの後。
- **境界テロップの後10秒以内に★★以上**を置く。第一候補は、確認済みの事実（笑いの源泉のギャップ）への公爵の反応。
- 境界テロップの文言は「※ここまで実際の報道（元媒体名・日付ほか）／ここから先はフィクション」（guardrails.md §5.2）。題材が架空の見本では「※架空の〜です」でよい。
- Xの画面を見せる場合は、架空のUIと架空のアカウント（アイコンは全部モブ田）で再現し、画面内に「PARODY」の透かしを入れる。実在の投稿のスクリーンショットや実在アカウントは映さない。
- タイトルの付け方は guardrails.md §5.4（「パロディ／妄想／もしも／ウソ裏話」のいずれか、実名の条件、ひねりを見せる）。

### 5-4 カットアウェイの書き方

- **入口の型**（すべてオリジナルの言い回し）：
  - 比較型：「〜した時よりはマシだ」
  - 回想型：「これは〜した時以来の屈辱だ」
  - 連想型：「〜と言えば、あれを思い出すな」
  - 仮定型：「もし〜だったら、こうなっていた」
  - 同時刻型：「一方その頃、〜では」
  - 唐突型：前触れなしに無関係な絵へ飛ぶ（M7 と兼ねる）
- **入口の一文だけで笑えるくらい具体的に書く**（M14）。「昔の失敗」ではなく、その回の小道具と数字を入れた一場面にする。
- 長さは**5〜15秒**（ショートは5秒以内）。台詞は1〜3行。
- 本筋と無関係でかまわない。ただし、言葉かモチーフで細くつなげる。
- **戻ったら説明しない**。無言で本筋に戻るか、ホオンが1行だけ反応する。
- 本数は本編で3〜5本、ショートで0〜1本。同じ入口の型を続けて使わない。**同じゲーム（例：公爵がモノとして値踏みされる屈辱）は1本まで**。本編では最低1本を唐突型・同時刻型・仮定型にし、はしご④⑤を絵で見せる。
- 置き場所は前半〜中盤（全体の3分の2まで）に集中させ、終盤は本筋とボタンに集中する。
- うち1本は、後半でコールバックする。
- カットアウェイにも 4-4 のハードラインは同じく適用する（RED の話題を「一瞬だけ」触れる、という使い方もしない）。
- 低予算での作り方：静止画にテロップとSEを付ける、フリー素材の実写を使う、配信者本人がモブ田を演じる、など。

### 5-5 CTA（キャラ口調で、その回のルールを使って毎回書く）

- 汎用の CTA（「登録は忠誠の証」型）は使わない。最後の数秒もボケにする。
- 型の見本（流用禁止）：
  - ルール「怒りは電力になる」の回：公爵「登録しない者の怒りも、余が電気に換える」
  - ルール「忘れられた記憶は土になる」の回：公爵「登録を忘れた者は、来月、余の鉢の土になっている」
  - ホオン「コメント欄で、公爵の計画の穴を教えてください。今日のは、たぶん40個あります」

## 6. セルフレビュー・ルーブリックとパンチアップ

### 6-1 手順（この順で必ずやる）

1. **冷たい読み合わせ**：★を全部外し、元ネタを知らない初見の視聴者として台詞だけを読み直し、★を付け直す（5-1 の較正で）。付け直す前と後の★の行数を記録する。
2. **ルーブリック13項目で採点する**（下表）。数えられるもの（台詞の字数、★行の間隔、★行の割合、参照ファイルの例文との一致）は、**目算でなく数える**（Bash の `python3 -c` などを使ってよい）。
3. **3案出し**：フック、はしご⑤、崩壊の一言、ボタン、すべての★★★について、別案を3つ書き、いちばん良いものを選ぶ。
4. **弱点トップ3**：全項目が合格でも、いちばん弱い★を3つ挙げて、差し替えるか、差し替えない理由を書く。
5. 不合格の項目を直す。**優先順位は 12（安全と権利）＞ 2（弱いボケを捨てる）＞ 1（密度）＞ ほか**。弱いボケを捨てて密度が割れたら、ルールから出た A 級の新しいボケを書き足す（弱いボケを残して密度を守らない）。

数える道具（引数: 台本ファイル、間隔の上限秒〔本編15・ショート7〕、事実ゾーンの開始と終了）:

```bash
python3 - 台本.md 15 0:35 0:55 <<'EOF'
import re,sys
a=sys.argv;L=int(a[2]) if len(a)>2 else 15
ts=lambda x:int(x.split(':')[0])*60+int(x.split(':')[1])
z=(ts(a[3]),ts(a[4])) if len(a)>4 else None
star=[];n=0;chars=0;long=[];sec=0
for s in open(a[1],encoding='utf-8'):
    m=re.match(r'\s*\[(\d+:\d\d)\]',s)
    if m: n+=1;sec=ts(m[1])
    elif not s.startswith(' '): continue
    s=re.sub(r'【間[^】]*】','',s)
    if '★' in s and (not star or star[-1]!=sec): star.append(sec)
    for d in re.findall(r'【(?:公爵|ホオン|モブ田|ナレ)】([^★【]*)',s):
        d=re.sub(r'（[^）]*）','',d).strip();chars+=len(d)
        long+=[(f'{sec//60}:{sec%60:02}',len(p)) for p in re.split('[。！？]',d) if len(p)>30]
f=lambda x:f'{x//60}:{x%60:02}'
g=lambda p,q:q-p-((z[1]-z[0]) if z and p<=z[0] and q>=z[1] else 0)
print('★行',len(star),'/',n,'行  台詞',chars,'字')
print(f'{L}秒超の★間隔',[(f(p),f(q),g(p,q)) for p,q in zip(star,star[1:]) if g(p,q)>L])
print('30字超の一息',long)
EOF
```

### 6-2 ルーブリック（13項目。1項目でも不合格なら直してから出す。第12項目の不合格は、該当場面を必ず差し替える）

| # | チェック | 合格基準 | 不合格のときの直し方 |
|---|---|---|---|
| 1 | **笑いの密度** | ★行の開始の間隔が本編15秒・ショート7秒以内（事実ゾーンは除く）。本編は★★以上が45秒以上空かず、★★★は4〜6個（最初は2:30まで、以降90秒以内ごと） | 空白の区間にルールから出たボケを足すか、その区間ごと削って詰める |
| 2 | **弱いボケを捨てる** | すべての★をA/B/Cで評価し、Cを全部、Bの下位を削ってある（目安で全体の20〜30%） | 削った穴は新しい A で埋める。弱いボケを説明で救わない |
| 3 | **説明台詞ゼロ** | ボケの直後に、その意味を言い直す台詞・テロップがない。ルールの説明は台詞のボケで1回だけ。ボタン前のフリは1行まで。ホオンが公爵の本音を解説しない | 言い直しの行を消す。ルールの説明は実演に替える |
| 4 | **現実の刃** | 笑いの源泉のギャップを本編で2回以上（ショートで1回以上）いじった。境界テロップの後10秒以内に★★以上がある | 公爵の反応で源泉を直接いじる。公の文言は guardrails.md §4.2-7 の範囲で引用してよい |
| 5 | **具体性** | 抽象名詞や丸い数字が残っていない | 「お菓子」→「半額シールが2枚重なったどら焼き」 |
| 6 | **文末オチと削り** | オチの単語が文の最後にあり、オチのあとに余計な言葉がない | 「〜なんですよね」「〜ということです」を消す。各台詞を2割削る |
| 7 | **キャラの声と毒** | 公爵の★★以上は M1 の形（貴族語→生活語）で、語彙バンクから1本に3語以上。4-3 の「毒の最低量」を満たす（該当台詞を引用する）。悪役の口に柔らかい語がない。素に戻るのは1回まで。ホオンは平熱、モブ田は善良 | 公爵の台詞を「貴族語→生活語」に組み直す。標的のない毒を、作中の相手に向け直す |
| 8 | **ゲームとエスカレーション** | すべてのボケが「この回のルール」から出ている（埋め草がない）。同じ文型は2回まで。段ごとに規模・被害・公爵の得が上がる。④⑤を絵で見せた。落下がある | ルールから外れたボケは削る。列挙は1段にまとめ、残りの段を場面で作る |
| 9 | **コールバック・ボタン・CTA** | コールバックが本編3つ以上（ショート1つ以上）。ボタンは冒頭とつながり、ルールが公爵に跳ね返る。天丼の数字と反応がこの回の新作。CTA もこの回のルールで言っている | 冒頭に種を足す。公爵が得をして終わるボタンを書き直す |
| 10 | **カットアウェイ** | 入口の一文だけで笑える。15秒以内。戻ったあとに説明していない。同じゲームが2本ない。本編に唐突型（M7）かメタ（M5）が1つ以上 | 入口をもっと具体的にする。同じゲームの2本目を別の型に替える |
| 11 | **オリジナリティ** | 参照ファイルの例文と8字以上一致する台詞・テロップが0（例外は冒頭の「見本の扱い」の①〜④だけ）。CTA・音声ディスクレーマー・素に戻る台詞・ダークターンは新作。実例の「本当の理由」の骨格を流用していない | 一致した行を、その回のルールから書き直す |

### 6-3 パンチアップの道具箱

- **3案出し**：弱いオチには必ず別案を3つ書き、いちばん良いものを選ぶ。
- **かぶせ**：ウケたボケのあとに、追い打ちを1〜2個足す。
- **縮小落ち**：エスカレーションの頂点で、一気に鉢植えサイズまで落とす。
- **跳ね返し**：ルールを公爵自身に当てる（M18）。
- **小道具化**：一般名詞を、受け皿・値札・延長コード・半額シールなど、この部屋の小道具に置き換える。
- **視点替え**：同じ場面を、モブ田側（何も知らない）やホオン側（全部知っている）から書き直してみる。
- **連打**：ジャンル・シフトの中で、ルールの出力を3〜5発、規模を上げながら連続で出し、最後をひねる（例：言い換え辞典風に「遅刻」→「時間に縛られない生き方」…→ 最後に人生そのもの）。
- **慣習チェック**：日本の慣習・暦・業界語を使うボケは、その慣習どおりか確かめる（葬儀なら友引、婚礼なら大安。会議なら「一旦持ち帰り」「〜の方向で」）。ずれていると、笑いより引っかかりが勝つ。

### 6-4 やってはいけない直し（実際の失敗例つき）

| やってはいけないこと | 失敗例 | 直し方 |
|---|---|---|
| ボケの直後に意味を言い直す | 「悪い知らせを、良さそうに言うだけの会議ですね」「余の計画が、この部屋でだけ通用しない」 | 削る。絵と【間】で見せる |
| ボタンを先に言ってしまう | 「1枚落ちた。6枚かあ。2でも3でも割れるね」→「消えた『6』、ここにありましたね」 | フリは1行まで。答えは言わせない |
| ホオンが公爵の本音を解説する | 「それ、寂しかっただけですよね」 | 削る。テロップや SE で脆さを見せる |
| ルールを何度も説明する | 0:00・0:13・0:18 で同じ前提を3回言う | 1回目だけ台詞のボケで言い、以降は実演 |
| ボケのあとに安全テロップを重ねる | 「この膠着は平均4分12秒続く」の直後に「※架空の数字です」 | 消す。境界テロップの後なら注記は要らない |
| 前提を説明するテロップ | コールドオープンの謎を4秒で「※ソーセージの話です」と明かす | 消す。謎はタイトルカードまで引っ張る |
| 公爵の口に柔らかい語 | 「……納めてくれたら、嬉しいが」 | 脅しか通告に替える |
| 標語のような公爵 | 「減ったら、『アップ』と呼べ」 | 貴族語で：「減少は不敬である。以後、上昇と呼べ」 |
| 同じ文型の列挙を段だと思う | 「給料が減れば〇〇アップ」「休みが減れば〇〇アップ」「寿命が減れば〇〇アップ」 | 2回で止め、3回目で裏切る。次の段は場面で |
| 現実のボケより弱い角度を採る | 話題になったコピーの皮肉に一度も触れず、別の数字パズルに逃げる | 3-2 の手順3に戻り、源泉のギャップから作り直す |

- ほかに: ツッコミを大声にして笑いを強制する／「ここが笑いどころです」とテロップで指示する。
