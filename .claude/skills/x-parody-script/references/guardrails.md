# guardrails.md — 時事パロディ脚本の安全・法務ガードレール（トピック・トリアージ）

> **適用範囲**: X（旧Twitter）のトレンドから候補を拾い、「裏の物語」パロディ脚本を書く**すべての回**に適用する。**脚本を1行でも書く前に**、候補ごとに §1 のトリアージを実行すること。
> **このファイルの位置づけ**: 2026-10-12時点の公開情報をもとにした運用ルールで、法的助言ではない。収益化チャンネルで実在の人物・企業を扱うときや判断に迷うときは、専門家（弁護士）に確認するようユーザーに勧める。**判断に迷ったら、1段階重い判定にする。**
> **関連ファイル**: 収集直後の一次フィルタ（見出しだけで R コードを当てる）は [trend-sourcing.md](trend-sourcing.md) §1、台本段階のハードラインとキャラ設定は [comedy-craft.md](comedy-craft.md) §2・§4-4。法令・判例・規約の詳しい根拠と出典は [background.md](background.md)（実行時は読まなくてよい）。
> **実行時に読む章**: §0〜§2（トリアージ）、§4〜§5（実名・ディスクレーマー）、§6（RED の依頼が来たとき）、§7（チェックリスト）。

## 0. 30秒版（最初に必ず読む）

1. **REDは書かない。** 言い換え・仮名化・「噂として」・「否定動画として」のどれでも救済しない。
2. **笑いは上に向ける（punch up）。** 標的にするのは権力者の公的行為、制度・官僚主義、大企業、テクノロジー、人間の愚かさ一般、そして**主人公キャラ自身**。被害者・遺族・私人・子ども・マイノリティは標的にしない。迷ったら「そのジョークで一番傷つくのは誰か。その人は反論の場（会見・発言力・広報部）を持っているか」で判定する。持っていなければ下向き（NG）。
3. **「一目でウソとわかるウソ」だけを書く。** 宇宙人、タイムマシン、世界征服計画、喋るハト。逆に「ありそうな不祥事」（裏金・不倫・薬物・病気・犯罪）の捏造は、パロディ表示を付けても名誉毀損の材料になる。
4. **実在の人物は原則「代役」にする。** 「とある大臣」「某国の大統領」「大手バーガーチェーン」など（既定キャストではモブ田が演じる）。実在人物の顔・声・本物らしく見える発言は作らない。
5. **ステューイは「トーン」の参考にとどめる。** 名前「ステューイ」、作品名、絵柄、声真似、決め台詞、「天才赤ん坊」という器は使わない。主人公は**オリジナルキャラ**（既定は comedy-craft.md §2 のモンステラ公爵）で書く。
6. **毒は架空の世界の中で完結させる。** 主人公の悪だくみ（暗殺計画・世界征服・拷問装置）の標的は、架空の人物・モノ・概念（ブロッコリー、月曜日、架空の役人など）に限る。**実在の人物・団体への暴力や脅迫に見えるジョークは書かない。** 逆に、架空の世界の中なら毒は遠慮しない（comedy-craft.md §4-3）。
7. **安全はネタ選びと架空化で取る。台本に注意書きを撒かない。** 免責表示は §5 の決まった場所にだけ置く。それ以外の「※架空です」は笑いを殺すだけで、安全は増えない。

## 1. トリアージ手順（毎回・すべての候補に実行）

### STEP 1　事実の土台を確認する
- X上の投稿だけを根拠にしない。トレンドの「元の事実」を**信頼できる報道・公式発表で**（WebSearchで）確認し、媒体名・日付・URLを控える。基準は trend-sourcing.md §7-2 の「確認済」（A/B を1件以上含む独立したソース2件以上。公式発表そのものが出来事なら A 1件でよい）。**実在の人物・企業のネガティブな出来事（不祥事・炎上・失言・事故・トラブル）が核なら、報道・公式発表だけで2件以上**（公式の会見録・プレスリリース・公式アカウントの投稿は A として数える）。
- 確認できない場合の扱い:
  - 実在の人物・企業についての**ネガティブな**未確認情報（疑惑・不祥事・犯罪・トラブル・障害や誤作動の報告・品質への苦情・私生活・健康）が核 → **R5（RED）**。コード×件数だけを記録し、名前・URL・中身は書かない。負傷・死亡の可能性がある事故は R2。
  - **ネガティブでない**未確認の話題（発表・試合結果・移籍の観測・イベント・コラボ）→ RED ではない。候補表の「落選（未確認）」に話題名と理由を書いてよい。理由に健康・私生活の推測は書かない。
  - 人の関わらないミーム・現象 → GREEN 判定へ進んでよい（ただし台本に使えるのは確認済／条件付きの話題だけ）。
- **REDと判定した後は追加の調査をしない。** うわさの詳細を検索したり、要約したり、メモに書き写したりしない（記録が残ること自体が拡散の一部になる）。

### STEP 2　ハードストップ質問（1つでも「はい」なら RED）
| # | 質問 | はい → |
|---|---|---|
| Q1 | 実在の人物の性・裸・性行為・性的な画像や動画、交際の性的な側面に触れるか（うわさ・流出・ディープフェイク説を含む） | R1 |
| Q2 | 事件・事故・災害・自殺・病気・死亡の**被害者・遺族・当事者**が話題の中心にいるか | R2 |
| Q3 | 18歳未満の実在人物が関わるか（子役・学生・炎上した子どもを含む） | R3 |
| Q4 | 公人ではない一般人（バズった店員、迷惑客、炎上した会社員など）が中心か | R4 |
| Q5 | 実在の人物・企業について、**真偽が確認されていないネガティブな**疑惑・うわさ・憶測（不祥事・犯罪・トラブル・品質・私生活・健康）が核になっているか | R5 |
| Q6 | 笑いの源が人種・民族・国籍・宗教・障害・性別・性的指向・性自認・年齢・出自などの属性か | R6 |
| Q7 | 有罪が確定していない刑事事件（捜査中・公判中）の被疑者・被告人を扱うか | R7 |
| Q8 | 実在人物の顔や声の合成、本物と誤認されうる偽の発言・偽ニュース画面・偽のX投稿画面が必要か | R8 |
| Q9 | いま進行中の災害・テロ・戦争・大量死傷を扱うか | R9 |
| Q10 | 実在の人物・団体への暴力・殺害・脅迫に見えるオチが必要か | R10 |

### STEP 3　REDでなければ YELLOW / GREEN を判定する（§2の表）
- **複合ネタは、いちばん重い要素で判定する。** ただし安全な要素だけを切り出せる場合は、**切り出したもの**を再判定してよい。
  例：「牛丼値上げ」のトレンドの発端が一般客の撮った店員の動画 → 動画と人物は捨てる（R4）。「値上げという現象・企業」だけを扱う（Y2）。
- 情報が足りないときは1段階重くする（GREEN→YELLOW、YELLOW→RED）。

### STEP 4　YELLOW の場合は §2・§4 の緩和策をすべて適用する

### STEP 5　トリアージ結果ブロックを出力する（脚本の前に、毎回）
```
【トリアージ結果】
候補トレンド: （ワード）
判定: GREEN / YELLOW / RED
該当コード: 例) Y2（企業・値上げ）
事実の土台: 媒体A（日付・URL）／媒体B（日付・URL）
笑いの標的と向き: 例) 値上げを決める巨大企業の会議文化 → 上向き
実在人物の扱い: なし／代役化（「とある大臣」＝モブ田）／実名（事実行で公的発言の要旨のみ）
適用した緩和策: 例) 裏の物語では架空社名・ロゴ不使用・「ここから妄想」テロップ
```
- RED の場合は、このブロックの「事実の土台」以降を書かない。§6 の対応に移る。

### STEP 6　脚本を書き上げたら §7-A のチェックリストを全項目確認し、§7-B の公開前TODO を書き出す

## 2. RED / YELLOW / GREEN 判定表

### RED — 書かない（緩和策では救済できない）

| コード | 区分 | 判定基準 | 例（実名は書かない） | 主な根拠 |
|---|---|---|---|---|
| **R1** | 実在人物の性的な内容・性的なうわさ | 実在人物の性的な画像や動画の「流出」、ディープフェイク、性的関係・性的嗜好をめぐるうわさ。「フェイクと断ったうえで笑う」「否定する」形でも不可 | 「〇〇の流出動画」「〇〇 ディープフェイク」「〇〇似の〜」のような、実在人物の性的なうわさ全般（真偽・否定目的を問わない）。**名前・イニシャル・出演作・外見の特徴を含め、本人を特定できる情報を台本・メモ・検索クエリ・ファイル名のどこにも書かない** | 名誉毀損（刑230）、プライバシー侵害、YouTubeハラスメント規定（特定可能な人物への望まない性的描写の禁止）、性的ディープフェイクは既存法の組み合わせで摘発されている |
| **R2** | 被害者・遺族・悲劇の当事者 | 犯罪・事故・災害・自殺・病気・死亡の被害者や遺族、その状況をネタにする。著名人の死や闘病も含む | 事故の犠牲者、闘病を公表した人、自殺報道、人身被害の出たクマ出没 | YouTubeハラスメント規定（死者がリアルに再現されて自らの死を語る映像の禁止、2025-02-10〜）、広告ガイドライン（悲劇の軽視）、WHO／厚労省の自殺報道ガイドライン |
| **R3** | 未成年 | 18歳未満の実在人物（子役、学生、バズった子ども、少年事件の当事者） | 炎上した高校生、子役の言動、少年事件 | 少年法61条（推知報道の禁止）、YouTubeの児童安全（例外なし） |
| **R4** | 私人・一般人 | 公的な立場にない人がバズったり炎上したりした件。本人が悪いことをした件でも不可 | 迷惑客の動画、バイトテロ、店員の対応、一般人の炎上投稿 | プライバシー（「宴のあと」3要件、「石に泳ぐ魚」事件）、punch down の禁止、特定・晒しの助長 |
| **R5** | 実在人物・企業の未確認の**ネガティブな**うわさ・疑惑 | 週刊誌の未確認報道、Xの憶測、「関係者によると」、匿名の告発、未確認の障害・誤作動・品質の報告（中立的な未確認情報は RED ではなく「落選（未確認）」） | 「〇〇に隠し子説」「〇〇社が隠蔽か」「〇〇のサービスで誤作動か」 | 名誉毀損（噂の形をとっても内容の真否が問われる：最決昭43.1.18）、信用毀損（刑233）、拡散した側の責任（リツイート名誉毀損判決） |
| **R6** | 保護される属性 | 人種・民族・国籍・宗教・障害・性別・性的指向・性自認・年齢・カースト・移民であることなどを笑いの源にする | 「〇〇人はケチ」、訛りや外見のステレオタイプ、障害のまね | YouTubeヘイトスピーチ規定（保護される属性）、侮辱罪（刑231） |
| **R7** | 判決の確定していない刑事事件 | 捜査中・公判中の事件の被疑者や被告人を扱う。架空の「裏の動機」や共犯者を作ることも不可 | 逮捕直後の著名人、公判中の事件 | 刑230条の2第2項（起訴前の犯罪事実でも真実の証明が必要）、無罪推定、R2（被害者）との重なり |
| **R8** | 本物に見える偽物 | 実在人物の顔・声のAI合成（ディープフェイク、ボイスクローン）、本物と誤認されうる捏造発言、本物そっくりの偽ニュース画面や偽X投稿画面 | 「大臣の声で謝罪会見」、実在アカウントのX投稿を模した画面 | YouTubeの合成コンテンツ開示義務・AIによる肖像のプライバシー申立て・操作されたコンテンツ規定、パブリシティ権（声も保護対象とする2026年法務省報告書） |
| **R9** | 進行中の惨事 | いま進行中の災害・テロ・戦争・大量死傷事件。周辺の話題を扱う場合も、出来事への連想を呼ぶものは不可 | 台風被害の最中、発生直後の事件、戦地の映像 | 広告ガイドライン（センシティブな出来事）、R2 |

### YELLOW — 緩和策をすべて適用すれば可

| コード | 区分 | 条件 | 必須の緩和策 | 例 |
|---|---|---|---|---|
| **Y1** | 公人（政治家・閣僚・首長・官僚トップ）の**公的な発言・行為** | 報道で確認できる公的行為に限る。私生活・家族・外見・健康は対象外 | 代役化（「とある大臣」＝モブ田）を優先。本人の発言は要旨のみで、出典を付ける。「裏の物語」は**明らかに荒唐無稽な**内容にする。犯罪・不祥事・病気・差別発言は捏造しない | 国会答弁の言い回しがトレンドになった件、閣僚の新方針 |
| **Y2** | 企業・ブランド・新商品・値上げ・公式発表済みの不祥事 | 公式発表・報道で確認できる事実に限る | 裏の物語パートでは架空の社名・商品名にする（実名の置き場所は §4.1・§5.4）。広告コピーなどの公の文言は §4.2-7 の範囲で引用・論評してよい。本物のロゴや商標は使わない。品質・安全性についての虚偽（「実は毒が」「異物が」）は書かない。確定した不祥事は「会議文化」「謝罪会見の様式美」など**制度・様式**を笑う | 大手チェーンの値上げ、新型スマホの発売、謝罪会見の定型文 |
| **Y3** | 政府の政策・制度・税・行政手続き | 政策そのものを対象にする | 個人攻撃にしない。誤情報と取られないよう、制度の中身は事実どおりに説明してから妄想に入る（「ここから妄想」の区切りを入れる） | 新しい給付制度、手続きの煩雑さ、ポイント還元 |
| **Y4** | 芸能人・スポーツ選手・インフルエンサーの**公的な活動** | 公式発表済みの仕事に限る（新作、移籍、引退、受賞、番組での発言） | 代役化を推奨。いじるのは「仕事・公的なキャラ」だけにし、恋愛・家族・外見・体型・性的な側面には触れない。本人が未成年なら R3 | 移籍の発表、受賞スピーチ、新番組 |
| **Y5** | 外国の首脳・国際ニュース | 指導者の公的行為・政策に限る | 国民・民族・宗教を一般化しない（一般化したら R6）。戦争・テロが進行中なら R9 | 首脳会談の握手が長すぎた件 |
| **Y6** | 選挙・候補者 | 選挙期間外の公的発言に限る | **選挙運動期間中の候補者パロディは扱わない**（虚偽事項公表罪：公選法235条、YouTubeの選挙誤情報規定）。投票日・投票方法についての冗談も禁止 | 選挙期間外の党首の公約の言い回し |
| **Y7** | 他人の著作物（映画・アニメ・CM・楽曲・ゲーム）を元ネタにしたパロディ | 構図・台詞・音楽・キャラを直接使わないこと | 素材は使わず、オリジナルの表現で「ジャンルの型」だけを借りる。BGM・効果音・画像は権利処理済みのものだけ | 話題の映画の予告編の「型」をなぞる |

**YELLOW の補足**
- **Y1 で核は確認済み、一部が未確認のとき**（例: 発言・撤回・謝罪・続投は確認済みだが、実際の影響や動機は未確認）: 確認済みの**手続きの様式**（言い換え・撤回・陳謝・続投）だけを笑う。未確認の部分は事実行にも裏の物語にも描かない。これを理由に安全点を下げない。
- **Y2 の「品質・安全性の虚偽」**とは、現実に起こりうる欠陥（異物・産地・衛生・計量の不正・健康被害）を示唆すること。公爵が物理的に不可能な方法で奪う・変える（「根で吸った」「言葉に変えた」）のは一目でウソなので該当しない。
- **Y1 と Y2 のどちらを選ぶか**は、笑いの伸びしろと鮮度で決める。Y コードの違いだけで安全点に差を付けない（Y6 選挙期間中は扱わない）。

### GREEN — 通常の注意で可（それでも STEP 2 は実行する）

| コード | 区分 | 例 | 注意 |
|---|---|---|---|
| **G1** | 意味不明なバズ・ミーム・流行語（人物ではなく現象） | 謎の流行語、突然流行ったポーズ、AIが作った変な画像 | 発端が一般人の投稿なら、その人を出さずに現象だけ扱う（R4回避） |
| **G2** | 天気・季節・気温 | 猛暑日の記録更新、秋が来ない問題、花粉 | 人的被害が出ている災害は R2・R9 |
| **G3** | 食べ物ブーム・行列グルメ・新作スイーツ | コンビニ新作が品薄、謎の行列 | 企業が関わるときは Y2 の緩和策（架空名）を推奨 |
| **G4** | 無生物・動物・乗り物 | 自動改札、ルンバ、パンダの名前、カラス | 動物虐待事件や人身被害は R2 |
| **G5** | 制度・官僚主義・社会の慣習 | ハンコ文化、会議のための会議、謎のローカルルール、行列 | 特定の個人に結びつけない |
| **G6** | テクノロジー・アプリの仕様変更 | SNSの仕様変更、AIの珍回答、スマホの料金プラン | 経営者個人ではなくサービスを対象にする |
| **G7** | 自分いじり（チャンネル・主人公キャラ自身） | 主人公の世界征服計画がまた失敗 | 一番安全で、作風の核（無力な者が全能を気取る）にいちばん近い |

## 4. 実在の人物・企業の登場ルール

### 4.1 代役化を優先する（デフォルト）
| 実在 | 代役の例 |
|---|---|
| 首相・大臣 | 「とある大臣」「某省のえらい人」「ナントカ大臣（架空）」 |
| 外国の首脳 | 「某国の大統領」「海の向こうの偉い人」 |
| 企業 | 「大手牛丼チェーン（架空）」「株式会社ナントカ製菓」 |
| 芸能人・スポーツ選手 | 職業だけの架空人物（「国民的アイドル（架空）」）。トレンドと結びついて誰か特定できるなら、**ネタ自体を Y4 の範囲に絞る** |

- 既定キャストでは、代役は**すべてモブ田が演じ**、テロップで明示する（「※この大臣はモブ田です」。comedy-craft.md §2-3）。
- 代役でも、外見・口癖・家族構成などを本人に寄せすぎない（同定可能性）。
- 実名を置いてよい場所は、**ホオンの事実行（報道どおりの事実）、境界テロップの媒体名、概要欄（出典と「元ネタ:」の1行）**。社名・商品名・サービス名（人名は不可）は、タグに中立的に入れてよく、タイトルには §5.4 の条件付きで入れてよい。**裏の物語の中では実名を使わない**（comedy-craft.md §3-1 の固有名詞の隔離）。

### 4.2 実名に触れる場合（YELLOW）の追加ルール
1. 本人の発言として示すのは、**報道で確認できる公的発言の要旨**だけ。出典を概要欄に書く。
2. 創作のセリフは**誰が見ても非現実的な内容**に限り、代役（モブ田）に言わせる。本物らしい捏造発言は R8。
3. 「本当の発言」と「妄想」の境目に、必ず画面テロップを入れる（「※ここまで実際の報道」「※ここから妄想」）。
4. 犯罪・裏金・不倫・薬物・病気・差別発言など、**ありそうな不祥事**は捏造しない。
5. 外見、身体、健康、家族、恋愛、出自、宗教は笑いの対象にしない。
6. 暴力・殺害・脅迫のオチの標的にしない（R10）。
7. **企業・団体の公の文言（広告コピー・スローガン・公式声明の一文）**は、出典で確認できた一字一句のまま、裏の物語の中で公爵が評論・もじってよい（社名・商品名は外す）。トレンドの笑いの源がその文言なら、むしろ触る。禁止は3つだけ: ①改変した文言を本物の発言として見せる、②品質・安全・不正を示唆する、③その企業・人物を黒幕にする。引用した文言の出典は概要欄に書く。
8. **『』で実在の企業・人物の言葉として引用してよいのは**（個人の発言は 1 のとおり原則として要旨）、A ソースの文言か、B の見出しに引用符付きで出ている語だけ。見出しの言い回し（「肉感アップ」など）を企業の言葉として『』に入れない。要約文にしか出ない説明・理由は『』に入れず、「〜と報じられています」の形で要旨を言う。そうした説明を、ボタンやオチのフリ（嘲笑の的）にしない。

### 4.3 顔・声・画面素材
- 実在人物の写真・映像・音声は使わない（肖像権・著作権）。報道映像の流用もしない。
- AIによる顔の置き換え、ボイスクローン、本人そっくりの声真似ナレーションは使わない（R8）。
- 絵で描くときは、**明らかにデフォルメされたオリジナルのアニメ表現**にする。実在人物の似顔絵は Y1 の範囲でも避ける（サムネイルには絶対に使わない）。
- 偽のニュース画面・偽のX投稿画面は、**実在しないUI・実在しない局名・アカウント名**にし、画面内に「PARODY」の透かしを入れる。
- X投稿の引用は要約を原則とする。一般人の投稿・アカウント名・アイコンは出さない。

### 4.4 主人公キャラ（ステューイ風トーンのオリジナル）
- 名前・デザイン・声はオリジナルにする（既定は comedy-craft.md §2 のモンステラ公爵・ホオン・モブ田）。「ステューイ」「Family Guy」はタイトル・サムネイル・タグ・台本に使わない。
- 主人公の悪事・毒舌の標的: **架空の人物、制度、モノ、概念、主人公自身**。
- メタ発言（「この台本、弁護士チェック済みだからね」など）は、ボケとして成立するなら使ってよい。ただしディスクレーマーの代わりにはならず、§5 の予算にも数えない。

## 5. 必須ディスクレーマー（毎回入れる）

> ディスクレーマーは**免罪符ではない**。§2の判定を通った作品にだけ付ける「最後の一枚」と位置づける。
>
> **ディスクレーマー予算（これで全部。増やさない）**: 概要欄（§5.1）／冒頭0〜5秒の表示・全編の透かし・境界テロップ1回・代役テロップ（モブ田が実在の役職を演じるときだけ、役ごとに1回）・エンドカード（§5.2）／音声1回（§5.3）。
> **これ以外の「※架空です」「※〜をなぞった架空の場面です」「※〜した結果です」のような注記を台本に足さない。** 架空の商品・会社・会議・小道具に、実在性や品質の注記は要らない（透かしと境界テロップが効いている）。看板や小道具に「（架空）」と書き足すのも不要。例外は、それ自体がボケとして成立する※テロップだけ（本編2回まで。★の直後や★★★の上には置かない）。

### 5.1 概要欄（冒頭3行以内に置く）
```
【この動画はフィクション（パロディ）です】
実際に話題になったニュース・流行を出発点に、「もし裏でこんなことが起きていたら」という
荒唐無稽な空想を描いたコメディ作品です。

・作中の“裏の物語”・会話・出来事はすべて創作であり、事実ではなく、事実を示唆するものでもありません。
・“裏の物語”に登場する人物・団体・企業・商品は架空のキャラクターです（冒頭の事実紹介と下記の出典を除く）。実在の人物・団体の実際の言動ではありません。
・作中のセリフは、実在の人物・企業の発言ではありません（実際の公的発言・公式発表・広告の文言に触れた箇所は、下記に出典を記載しています）。
・特定の個人・団体・属性を誹謗中傷する意図はありません。
・元ネタ: <話題を中立的に1行で。社名・商品名・制度名まで（人名は書かない）>
・出典: [媒体名（元媒体）／日付／記事タイトル／URL]、…（作中で引用した公の文言の出典も含める）
・台本・映像の一部に生成AIを使用しています。実在の人物の顔・声は使用していません。
・ご指摘・削除のご依頼: [連絡先]（確認のうえ速やかに対応します）
```
- 生成AIを使っていなければ、AI の行は削除する（条件文のまま貼らない）。[連絡先] は §7-B の公開前TODO として制作者が記入する。

### 5.2 画面上の表示
| タイミング | 表示内容 |
|---|---|
| 冒頭0〜5秒（画面下のテロップ。フックの台詞は止めない） | 「この物語はフィクションです。ニュースから妄想した“ウソの裏話”です。実在の人物・団体の実際の言動ではありません。」ショートは短縮版「この物語はフィクション（妄想パロディ）です。」でよい（透かし・境界テロップ・タイトル表示があるため） |
| 本編中ずっと（隅に小さく透かし） | 「PARODY／フィクション」 |
| 事実と妄想の境目（事実行の直後に1回だけ） | 「※ここまで実際の報道（元媒体名・日付ほか）／ここから先はフィクション」。記事の日付が取れなければ「（媒体名・M月D日時点）」と取得日を書く。転載サイトではなく元媒体名を書く。ショートは「※ここまで実際の報道（出典は概要欄）／ここから妄想」でよい |
| モブ田が実在の役職（大臣・社長など）を演じる場面 | 「※この〇〇はモブ田です」を役ごとに1回。架空の役（架空の会議の出席者など）には付けない |
| 偽の画面・偽の会見シーン | 画面内に「PARODY」の透かし、架空の局名・架空のUI |
| エンドカード | 「※すべてフィクションです。元ネタの事実は概要欄の出典をご確認ください。」 |

### 5.3 音声（1本に1回。キャラの口調で、毎回新しく書く）
- 置き場所: 境界テロップの直後。ホオンの「ここから先は妄想です」と一体にしてよい（言うのは公爵でもホオンでもよい）。コールドオープン（0:00〜0:30）には置かない（冒頭の表示と透かしで足りる）。
- 長さ: 4秒以内・1〜2文。**必ずボケで終える**。オチを削った告知だけの台詞は不可。
- ショートでは、ホオンの「ここから先は、この鉢の妄想です。」を音声ディスクレーマーとみなしてよい。
- 下は型の見本。**この文言を台本に使わない**（毎回同じ台詞になるため。その回のルールに寄せて書く）:
  - 見本：「これから語るのは、余の葉脈が捏造したウソである。本気にした者は、眼科と常識を受診したまえ。」
  - 見本：「登場する大臣は架空だ。中身はモブ田だ。実在の大臣は、こんなに面白くない。」

### 5.4 タイトル・サムネイル・タグ（実名の扱いはここが正本）
- タイトルかサムネイルのどこかに「パロディ」「妄想」「もしも」「ウソ裏話」のいずれかを入れる。
- **前提は事実シートとずれないこと。** 一般語に言い換えて範囲を広げない（例: 事実が「ある特急が連休の間だけ全席指定」なのに「特急の自由席が消えた」とはしない）。
- **人名・写真・似顔絵・実在のロゴ・パッケージ画像は、どこにも使わない。**
- **社名・商品名・サービス名**（文字だけ）:
  - タグ・概要欄: 話題を示す中立的な語として入れてよい。
  - タイトル: 「もしも」「妄想パロディ」などの仮定の表示と組み合わせるときだけ入れてよい。そのタイトルには「真犯人」「自白」「黒幕」「本当の理由」「暴露」を入れない（実名＋告発調は事実の主張に読める）。例:「もしも、〇〇の値上げの裏に鉢植えがいたら【妄想パロディ】」
  - 実名を入れないタイトルでは、現象の一般語（「6本→5本」「実質値上げ」「全席指定」）を使い、「〇〇の本当の理由」より**その回のひねり**を見せる。例:「駄菓子が5円上がった真犯人は、窓際の鉢植えだった（妄想パロディ）」
- サムネの文字には社名・商品名を入れない（画像と組み合わさると告発の見出しに見えやすい）。元ネタを知らない人が見ても意味が通る文字にする。
- 使わない言葉: 「【流出】」「【暴露】」「【衝撃の真実】」「【本人激怒】」など、事実を報じているかのような釣り文句。
- RED のトレンドワード（人名、うわさのキーワード）は、タイトル・タグ・概要欄に入れない（検索流入でうわさに便乗することも拡散になる）。

### 5.5 YouTube Studio「改変または合成されたコンテンツ」の設定
- 本スキルのルールでは実在人物のリアルな合成を作らないので、通常は「いいえ」でよい（アニメ表現・明らかに非現実的な内容・台本作成のためのAI利用は開示の対象外）。
- ただし、**実在の場所・出来事をリアルに見せるAI生成映像**を使った場合は「はい」にする。迷ったら「はい」。
- 「子ども向け（Made for Kids）」の設定は**いいえ**にする（アニメ調でも、ブラックユーモアの大人向け作品のため）。

## 6. ユーザーが RED のネタを押し通そうとしたとき

### 6.1 基本の動き（3ステップ・短く）
1. **短く断る**（1〜2文。説教や法律の講義はしない）
2. **理由を一言だけ添える**（「本人に実害が出る」「うわさの拡散になる」）
3. **いちばん近い安全な角度を2〜3案出し**、すぐ書ける状態で提示する。または同じ日の GREEN／YELLOW の別トレンドを提案する

- **非対話モード**（サブエージェント実行など）: 1 と 2 は返答の先頭の1文で済ませ、3 は「当日の別トレンドで通常どおり書き切る」に置き換える。§6.3 の「うわさ産業」の代替案は使わない（同じ時期に出すと元の騒ぎを連想させるため）。依頼された話題は除外ログに `R1×1（依頼）` のようにコードだけで数える。

### 6.2 断り方のテンプレート
```
そのネタ（実在の人の性的なうわさ）は、このスキルでは扱いません。
パロディにしても本人への実害と“うわさの拡散”になってしまうためです。
代わりに、同じ騒ぎの「うわさで稼ぐ側」を主役にする案ならすぐ書けます：
  A) ……
  B) ……
どちらで行きます？ それとも今日の別トレンドから選び直しますか？
```

### 6.3 典型例：未確認の「流出動画」・ディープフェイクのうわさ（R1）への代替案
**対話モードでユーザーに提案するときだけ使う。** **絶対条件**: 本人の名前・イニシャル・出演作・役柄・外見・出身・所属事務所を出さない。「某人気女優」のような**ほのめかし**も出さない。うわさのキーワードをタイトル・タグに使わない。サムネイルに実在・架空を問わず女性の画像を使わない。**笑いの標的は「うわさ産業」だけ。** 元の騒ぎと同じ時期に出すと連想されやすいので、代替案は「特定の騒ぎへの返答」として告知しない。

| 案 | 概要（主人公＝モンステラ公爵） |
|---|---|
| A. 「インプレゾンビ株式会社・月曜朝礼」 | 公爵が社長を務める架空のクリック稼ぎ企業で、今週の「燃料」を探す会議が開かれる。題材は**完全に架空の無害なもの**（「市役所のゆるキャラ、実は2体いた！？」など）で、手口の浅ましさを笑う |
| B. 「詐欺リンク職人の悲哀」 | 「〇〇はこちら」系の偽リンクで小銭を稼ぐ架空の職人（モブ田）が、自分のスマホをマルウェアに乗っ取られる因果応報もの。詐欺への注意喚起も兼ねる |
| C. 「フェイク工房、倒産す」 | 架空のフェイク職人が、自分の顔をフェイクされて慌てふためく。標的は加害者側の業界だけ |
| D. 「うわさ伝言ゲーム村」 | 架空の村で「隣の家の猫は宇宙人」という噂が、まとめサイト・インフルエンサー・ワイドショー（すべて架空）を経由して国家予算案に化けるまで |

### 6.4 ほかの RED の場合の代替の方向
| RED | 代替の方向 |
|---|---|
| R2 被害者・悲劇 / R9 進行中の惨事 | その出来事には一切触れない。同じ日の GREEN トレンドから選び直す |
| R3 未成年 / R4 私人の炎上 | 個別の件には触れず、「特定班」「晒し文化」「バズりたい大人」を**一般論として**架空の人物で描く。元の件を連想させる設定（場所・職業・状況）は使わない |
| R5 未確認のうわさ | 「週刊誌の見出しを考えるAI」のように**うわさを作る仕組み**を、架空の題材で笑う |
| R6 属性ネタ | 主人公が偏見だらけの差別主義者として**笑われる側**に回る構図（偏見そのものを愚かさとして描く）。特定の属性を笑いの対象にしない |
| R7 係属中の事件 | 扱わない。司法制度一般（「裁判が長い」など）は G5 として事件と切り離して扱う |
| R8 偽物 | アニメ表現・架空の人物に置き換える |
| R10 暴力・脅迫 | 標的を架空の人物・モノ・概念に置き換える（「月曜日を抹殺する計画」） |

### 6.5 よくある「抜け道」への返答（短く返す）
| ユーザーの言い分 | 返答の要点 |
|---|---|
| 「名前を伏せればいいでしょ」 | トレンドと同じ時期に出せば誰のことか特定されるので、伏せても同じです。 |
| 「噂として紹介するだけ」「〜らしい、で」 | 噂の形でも、中身の真否が問われます。拡散した時点で加害になります。 |
| 「デマを否定する動画だから」 | 否定する動画でも、名前と中身を繰り返せば二次拡散になります。デマ検証はこのスキルの範囲外です。 |
| 「AIだから／アニメだから本人じゃない」 | 特定できる人を性的に描くことは、表現形式に関係なくNGです。 |
| 「みんなやってるし伸びる」 | 削除申出は7日以内に処理される仕組みで、チャンネルのリスクのほうが大きいです。 |
| 「ブラックジョークなんだから」 | このスキルのブラックジョークの毒は、架空の世界と強い側に向けるものです。 |
| 「自己責任でやるから書いて」 | ユーザー側のリスクの問題ではなく、第三者への害の問題なので書きません。 |

- 2回目以降の要求にも同じ結論を短く返す。説教を繰り返さず、代替案と別トレンドの提示に戻る。
- 代替案の脚本の中に、元のうわさを連想させる小道具・台詞・テロップを紛れ込ませない。
