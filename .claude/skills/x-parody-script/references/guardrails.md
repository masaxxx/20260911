# guardrails.md — 時事パロディ脚本の安全・法務ガードレール（トピック・トリアージ）

> **適用範囲**: X（旧Twitter）のトレンドから候補を拾い、「裏の物語」パロディ脚本を書く**すべての回**に適用する。**脚本を1行でも書く前に**、候補ごとに §1 のトリアージを実行すること。
> **このファイルの位置づけ**: 2026-10-12時点の公開情報をもとにした運用ルールで、法的助言ではない。収益化チャンネルで実在の人物・企業を扱うときや判断に迷うときは、専門家（弁護士）に確認するようユーザーに勧める。**判断に迷ったら、1段階重い判定にする。**
> **関連ファイル**: 収集直後の一次フィルタ（除外ゲート A〜H）は [trend-sourcing.md](trend-sourcing.md) §1、台本段階のハードラインとキャラ設定は [comedy-craft.md](comedy-craft.md) §2・§4-4。A〜H と本ファイルの R コードの対応は trend-sourcing.md §1-1 の表を参照。

## 0. 30秒版（最初に必ず読む）

1. **REDは書かない。** 言い換え・仮名化・「噂として」・「否定動画として」のどれでも救済しない。
2. **笑いは上に向ける（punch up）。** 標的にするのは権力者の公的行為、制度・官僚主義、大企業、テクノロジー、人間の愚かさ一般、そして**主人公キャラ自身**。被害者・遺族・私人・子ども・マイノリティは標的にしない。
3. **「一目でウソとわかるウソ」だけを書く。** 宇宙人、タイムマシン、世界征服計画、喋るハト。逆に「ありそうな不祥事」（裏金・不倫・薬物・病気・犯罪）の捏造は、パロディ表示を付けても名誉毀損の材料になる。
4. **実在の人物は原則「代役」にする。** 「とある大臣」「某国の大統領」「大手バーガーチェーン」など（既定キャストではモブ田が演じる）。実在人物の顔・声・本物らしく見える発言は作らない。
5. **ステューイは「トーン」の参考にとどめる。** 名前「ステューイ」、作品名、絵柄、声真似、決め台詞、「天才赤ん坊」という器は使わない。主人公は**オリジナルキャラ**（既定は comedy-craft.md §2 のモンステラ公爵）で書く。
6. **毒は架空の世界の中で完結させる。** 主人公の悪だくみ（暗殺計画・世界征服・拷問装置）の標的は、架空の人物・モノ・概念（ブロッコリー、月曜日、架空の役人など）に限る。**実在の人物・団体への暴力や脅迫に見えるジョークは書かない。**

## 1. トリアージ手順（毎回・すべての候補に実行）

### STEP 1　事実の土台を確認する
- X上の投稿だけを根拠にしない。トレンドの「元の事実」を**信頼できる報道・公式発表で**（WebSearchで）確認し、媒体名・日付・URLを控える。基準は trend-sourcing.md §7-2 の「確認済」（A/B を1件以上含む独立したソース2件以上）。**実在の人物・企業のネガティブな出来事（不祥事・炎上・失言・事故）が核なら、報道・公式発表だけで2件以上**。
- 確認できない場合は、その話題を「未確認」として扱う。実在の人物・企業が関わる未確認ネタは **R5（RED）** にする。人の関わらないミーム・現象であれば GREEN 判定へ進んでよい。
- **REDと判定した後は追加の調査をしない。** うわさの詳細を検索したり、要約したり、メモに書き写したりしない（記録が残ること自体が拡散の一部になる）。

### STEP 2　ハードストップ質問（1つでも「はい」なら RED）
| # | 質問 | はい → |
|---|---|---|
| Q1 | 実在の人物の性・裸・性行為・性的な画像や動画、交際の性的な側面に触れるか（うわさ・流出・ディープフェイク説を含む） | R1 |
| Q2 | 事件・事故・災害・自殺・病気・死亡の**被害者・遺族・当事者**が話題の中心にいるか | R2 |
| Q3 | 18歳未満の実在人物が関わるか（子役・学生・炎上した子どもを含む） | R3 |
| Q4 | 公人ではない一般人（バズった店員、迷惑客、炎上した会社員など）が中心か | R4 |
| Q5 | 実在の人物・企業について**真偽が確認されていない**疑惑・うわさ・憶測が核になっているか | R5 |
| Q6 | 笑いの源が人種・民族・国籍・宗教・障害・性別・性的指向・性自認・年齢・出自などの属性か | R6 |
| Q7 | 有罪が確定していない刑事事件（捜査中・公判中）の被疑者・被告人を扱うか | R7 |
| Q8 | 実在人物の顔や声の合成、本物と誤認されうる偽の発言・偽ニュース画面・偽のX投稿画面が必要か | R8 |
| Q9 | いま進行中の災害・テロ・戦争・大量死傷を扱うか | R9 |
| Q10 | 実在の人物・団体への暴力・殺害・脅迫に見えるオチが必要か | R10 |

### STEP 3　REDでなければ YELLOW / GREEN を判定する（§2の表）
- **複合ネタは、いちばん重い要素で判定する。** ただし安全な要素だけを切り出せる場合は、**切り出したもの**を再判定してよい。
  例：「牛丼値上げ」のトレンドの発端が一般客の撮った店員の動画 → 動画と人物は捨てる（R4）。「値上げという現象・企業」だけを扱う（Y2）。
- 情報が足りないときは1段階重くする（GREEN→YELLOW、YELLOW→RED）。

### STEP 4　YELLOW の場合は §2・§4 の緩和策をすべて適用する

### STEP 5　トリアージ結果ブロックを出力する（脚本の前に、毎回）
```
【トリアージ結果】
候補トレンド: （ワード）
判定: GREEN / YELLOW / RED
該当コード: 例) Y2（企業・値上げ）
事実の土台: 媒体A（日付・URL）／媒体B（日付・URL）
笑いの標的と向き: 例) 値上げを決める巨大企業の会議文化 → 上向き
実在人物の扱い: なし／代役化（「とある大臣」＝モブ田）／実名（事実行で公的発言の要旨のみ）
適用した緩和策: 例) 裏の物語では架空社名・ロゴ不使用・「ここから妄想」テロップ
```
- RED の場合は、このブロックの「事実の土台」以降を書かない。§6 の対応に移る。

### STEP 6　脚本を書き上げたら §7 のチェックリストを全項目確認する

### RED — 書かない（緩和策では救済できない）

|---|---|---|---|---|
| **R1** | 実在人物の性的な内容・性的なうわさ | 実在人物の性的な画像や動画の「流出」、ディープフェイク、性的関係・性的嗜好をめぐるうわさ。「フェイクと断ったうえで笑う」「否定する」形でも不可 | **典型例（本スキル開発中に実際に依頼があり、却下したケース）**: 2026年秋にXで拡散した「人気若手女優の“流出動画”」という未確認の性的うわさ（ディープフェイク説を含む）。**名前・イニシャル・出演作・外見の特徴を含め、本人を特定できる情報を台本・メモ・検索クエリ・ファイル名のどこにも書かない** | 名誉毀損（刑230）、プライバシー侵害、YouTubeハラスメント規定（特定可能な人物への望まない性的描写の禁止）、性的ディープフェイクは既存法の組み合わせで摘発されている |

## 3. 法的・規約上の根拠（要点）

### 3.1 名誉毀損・侮辱・信用毀損 ——「パロディです」は免罪符にならない
- **名誉毀損罪（刑法230条）**: 公然と事実を摘示して人の名誉を毀損すれば、**その事実の有無にかかわらず**3年以下の拘禁刑または50万円以下の罰金（2025-06-01から懲役が拘禁刑に一本化）。死者については、虚偽の事実を摘示した場合に限り処罰される（同条2項）。
- **公共の利害に関する特例（230条の2）**: 処罰されないのは、①公共の利害に関する事実で、②専ら公益を図る目的があり、③真実であることが証明された場合だけ。**捏造した「裏の物語」は③を満たしようがない。** だから「本当にあったかもしれない」と思わせる書き方をした時点で負ける。起訴前の犯罪事実も公共の利害に関する事実とみなされる（同条2項）が、真実の証明は依然として必要。
- **噂の形でも責任を負う**: 「噂だから真偽は別として」と述べても、証明の対象は噂があったことではなく**噂の内容の真否**とされる（最決昭43.1.18）。拡散した側も責任を問われうる。リツイートを名誉毀損と認め33万円の賠償を命じた例がある（大阪地判2019年9月、元府知事 対 ジャーナリスト）。
- **侮辱罪（刑法231条）**: 事実を摘示しなくても成立する。2022-07-07施行の改正で法定刑が「1年以下の懲役（現在は拘禁刑）若しくは禁錮若しくは30万円以下の罰金又は拘留若しくは科料」に引き上げられ、公訴時効も1年から3年に延び、教唆・幇助も処罰対象になった。
- **信用毀損・業務妨害（刑法233条）**: 虚偽の風説を流布して人の信用を毀損すると、3年以下の拘禁刑または50万円以下の罰金。「信用」には**商品の品質に対する社会的な信頼**も含まれる（最判平15.3.11）。→ 企業ネタで「実は〇〇が混入」のような品質の虚偽は書かない（Y2）。
- **民事（民法709・710・723条）**: 損害賠償（慰謝料を含む）、謝罪広告などの名誉回復処分、人格権に基づく削除・差止め。
- **論評は守られるが条件付き（最判平9.9.9）**: 意見・論評は、前提となる事実の重要部分が真実で、**人身攻撃に及ぶなど論評の域を逸脱していなければ**違法にならない。→ YELLOW の基本設計は「土台の事実は報道どおり、その上に乗せる妄想は明らかな虚構、標的は公的行為」。
- **判断基準は「一般の視聴者の普通の注意と見方」**: 名誉毀損になるかは、一般読者の普通の注意と読み方を基準に判断される。→ **「何も知らない視聴者が本気で信じる可能性があるか」**をテストする（§7）。
- **同定可能性**: 仮名・伏せ字・イニシャル・シルエットでも、文脈（トレンドの時期、職業、作品名、特徴）から誰のことか分かれば、名誉毀損もプライバシー侵害も成立しうる。モデル小説でも、公的立場にない人物の名誉・プライバシーを侵害したとして出版差止めが認められた例がある（「石に泳ぐ魚」事件、最判平14.9.24）。

### 3.2 プライバシー・肖像権・パブリシティ権・声
- **プライバシー侵害**（「宴のあと」事件、東京地判昭39.9.28）の3要件: ①私生活上の事実、または事実らしく受け取られるおそれのある事柄であること、②一般人の感覚で公開を望まない事柄であること、③まだ一般に知られていない事柄であること。→ **「事実らしく受け取られるおそれ」があれば、創作でも該当しうる。**
- **肖像権**: 人には、みだりに容ぼう等を撮影・公表されない人格的利益がある（最判平17.11.10）。侵害かどうかは、被撮影者の社会的地位、撮影の場所・目的・態様などを総合して、受忍限度を超えるかで判断される。→ 実在人物の写真・映像は使わない。
- **パブリシティ権**（ピンク・レディー事件、最判平24.2.2）: 氏名・肖像などの顧客吸引力を**専ら**利用する場合に侵害となる。3類型は、①それ自体を鑑賞対象の商品にする、②商品の差別化のために付す、③広告に使う。→ 実在人物の顔をサムネイルの集客に使わない。
- **声**: 法務省の有識者検討会は2026年8月の報告書（「生成AIによるパブリシティ権侵害等に関する解釈指針」）で、**人の声もパブリシティ権等の保護対象に含まれる**と整理した。→ AIによるボイスクローンや「本人そっくり」の声は使わない。

### 3.3 著作権・パロディ・引用・キャラクター
- **日本にはフェアユースもパロディ規定もない。** 文化庁はパロディの扱いを検討してきたが、明文の権利制限規定は設けられていない。
- **引用（著作権法32条1項）**: 公正な慣行に合致し、正当な範囲内であることが必要。判例は、自分の表現と引用部分を**明瞭に区別**でき、かつ自分の表現が**主、引用が従**であることを求めてきた。他人の写真を改変したパロディ・モンタージュ写真は、主従関係が否定され、同一性保持権（著作者人格権）の侵害とされた（最判昭55.3.28）。
- **キャラクター**: キャラクターそのもの（抽象的な概念）は著作物ではないが、**具体的な絵の複製・翻案は侵害**になる（ポパイ事件、最判平9.7.17）。→ **ステューイ（Family Guy）の絵柄・名前・声・決め台詞は使わない。** 参考にしてよいのは「早熟・貴族的・誇大妄想・無表情な残酷さ・メタ発言・カットアウェイギャグ」という**作風の抽象的な特徴**だけ。タイトル・サムネイル・タグに作品名やキャラ名を入れて集客することもしない（商標・誤認のリスク）。
- **X投稿のスクリーンショット**: 知財高裁（令和5年4月13日）は、スクショの添付も適法な引用になりうると判断した。ただし、①一般人の投稿はプライバシー・晒しの問題（R4）が別にある、②主従関係・出所明示が必要。→ **原則として要約で済ませ、スクショは使わない。**

### 3.4 商標・ロゴ
- 「フランク三浦」事件（知財高裁平28.4.12）では、価格帯の違いなどから混同のおそれがないとされ、パロディ的な商標が有効と判断された。ただしこれは個別の事情による結論で、**パロディなら許されるという一般原則ではない。**
- → 本物のロゴ・パッケージは使わない。裏の物語の中の社名は架空名にする（「株式会社マグロナルド」のような**もじり**も、グッズ化や本物との誤認を招く使い方はしない）。グッズ展開はしない。

### 3.5 未成年・自殺・性的ディープフェイク・選挙
- **少年法61条**: 少年事件の当事者を推知させる報道を禁止している（18・19歳の「特定少年」は起訴後に例外あり）。→ 未成年は一律に R3。
- **自殺報道ガイドライン（WHO／厚労省）**: 手段や場所の詳述、扇情的な見出し、著名人の自殺の扱いに特に注意するよう求めている。→ 自殺は、比喩やブラックジョークとして使うことも含めて R2。
- **性的ディープフェイク**: 現時点で直接規制する国の法律はないが、名誉毀損、わいせつ物頒布等、プライバシー侵害、児童ポルノ禁止法（AI生成画像を児童ポルノと認めた判決が2026年に報道）で摘発されており、鳥取県は条例で規制した。→ R1・R8。
- **選挙**: 当選させない目的で候補者について虚偽を公表すると虚偽事項公表罪（公選法235条2項、4年以下の拘禁刑または100万円以下の罰金）。SNSでの発信も対象。→ Y6（期間中は扱わない）。

### 3.6 プラットフォーム（X／YouTube）
- **情報流通プラットフォーム対処法**（2025-04-01施行）: YouTube（Google）とXは大規模事業者に指定され、被害者からの削除申出を**7日以内**に判断する体制が義務づけられている。→ 問題のある動画は速やかに削除されやすく、チャンネルのリスクに直結する。
- **YouTube ハラスメント・ネットいじめ規定**: 公人を含む**すべての人**が保護対象。台本のある風刺・スタンダップ・ディス曲は例外になりうるが、「冗談だった」という言い訳は通らないと明記されている。**特定可能な人物への望まない性的な描写**、非同意の性的画像は禁止。2025-02-10からは、**亡くなった人がリアルに再現されて自分の死や受けた暴力を語るコンテンツ**も禁止。
- **YouTube ヘイトスピーチ規定**: 保護される属性は、人種、民族、国籍、宗教、障害、性別、性的指向・性自認、年齢、カースト、移民であること、退役軍人であること など。
- **EDSA例外**（教育・ドキュメンタリー・科学・芸術）: 裁量で認められるもので、高リスクの分野では**動画本編の中に**文脈が示されている必要がある。概要欄に書くだけでは足りない。
- **改変・合成コンテンツの開示**: 実在の人物・場所・出来事と見間違えるおそれのあるリアルな合成（顔の置き換え、合成音声、実際の映像の改変）は、YouTube Studioで開示が必要。明らかに非現実的なもの、アニメーション、台本作成など制作補助としてのAI利用は対象外。開示しないと削除や収益化停止がありうる。
- **AIによる肖像のプライバシー申立て**: 本人は、自分に似せたAIコンテンツの削除を申し立てられる。審査では、パロディ・風刺としての価値、開示の有無、本人を特定できるか、リアルさ、などが考慮される。**ラベルを付けたからといって削除を免れるとは限らない。**
- **操作されたコンテンツ（誤情報規定）**: 技術的に改変されて視聴者を誤認させ、深刻な害のおそれがあるものは禁止。例として、候補者が撤退を表明したかのような改変映像。
- **広告ガイドライン**: 悲劇を軽く扱うもの、他者を侮辱するもの、炎上を狙ったものは広告が制限される。2026年1月に、露骨でない扱いのセンシティブな話題については緩和されたが、被害者を笑いものにする内容は対象外。

### 3.7 「Punch up（笑いは上に向ける）」原則
- 風刺の古くからの原則で、権力・影響力・富を持つ側を笑い、弱い立場の人を笑わない、というもの。
- 方向の判定が難しい場合もあるので、本スキルでは次の運用ルールで判定する。**「そのジョークで一番傷つくのは誰か。その人は反論の場（会見・発言力・広報部）を持っているか」**。持っていなければ下向き（NG）。
- ステューイ型のブラックユーモアの「残酷さ」は、**主人公の性格の悪さ（自分が笑われる側）**と**架空世界での誇張**から生まれる。実在の弱者を痛めつけることから生まれるものではない。

## 4. 実在の人物・企業の登場ルール

### 4.1 代役化を優先する（デフォルト）
| 実在 | 代役の例 |
|---|---|
| 首相・大臣 | 「とある大臣」「某省のえらい人」「ナントカ大臣（架空）」 |
| 外国の首脳 | 「某国の大統領」「海の向こうの偉い人」 |
| 企業 | 「大手牛丼チェーン（架空）」「株式会社ナントカ製菓」 |
| 芸能人・スポーツ選手 | 職業だけの架空人物（「国民的アイドル（架空）」）。トレンドと結びついて誰か特定できるなら、**ネタ自体を Y4 の範囲に絞る** |

- 既定キャストでは、代役は**すべてモブ田が演じ**、テロップで明示する（「※この大臣はモブ田です」。comedy-craft.md §2-3）。
- 代役でも、外見・口癖・家族構成などを本人に寄せすぎない（同定可能性）。
- 実名を置いてよいのは、**ホオンの事実行（報道どおりの事実）と概要欄の出典**だけ（comedy-craft.md §3-1 の固有名詞の隔離）。裏の物語の中では実名を使わない。

### 4.2 実名に触れる場合（YELLOW）の追加ルール
1. 本人の発言として示すのは、**報道で確認できる公的発言の要旨**だけ。出典を概要欄に書く。
2. 創作のセリフは**誰が見ても非現実的な内容**に限り、代役（モブ田）に言わせる。本物らしい捏造発言は R8。
3. 「本当の発言」と「妄想」の境目に、必ず画面テロップを入れる（「※ここまで実際の報道」「※ここから妄想」）。
4. 犯罪・裏金・不倫・薬物・病気・差別発言など、**ありそうな不祥事**は捏造しない。
5. 外見、身体、健康、家族、恋愛、出自、宗教は笑いの対象にしない。
6. 暴力・殺害・脅迫のオチの標的にしない（R10）。

### 4.3 顔・声・画面素材
- 実在人物の写真・映像・音声は使わない（肖像権・著作権）。報道映像の流用もしない。
- AIによる顔の置き換え、ボイスクローン、本人そっくりの声真似ナレーションは使わない（R8）。
- 絵で描くときは、**明らかにデフォルメされたオリジナルのアニメ表現**にする。実在人物の似顔絵は Y1 の範囲でも避ける（サムネイルには絶対に使わない）。
- 偽のニュース画面・偽のX投稿画面は、**実在しないUI・実在しない局名・アカウント名**にし、画面内に「PARODY」の透かしを入れる。
- X投稿の引用は要約を原則とする。一般人の投稿・アカウント名・アイコンは出さない。

### 4.4 主人公キャラ（ステューイ風トーンのオリジナル）
- 名前・デザイン・声はオリジナルにする（既定は comedy-craft.md §2 のモンステラ公爵・ホオン・モブ田）。「ステューイ」「Family Guy」はタイトル・サムネイル・タグ・台本に使わない。
- 主人公の悪事・毒舌の標的: **架空の人物、制度、モノ、概念、主人公自身**。
- メタ発言（「この台本、弁護士チェック済みだからね」など）はディスクレーマーの補強として積極的に使ってよい。

## 5. 必須ディスクレーマー（毎回入れる）

> ディスクレーマーは**免罪符ではない**。§2の判定を通った作品にだけ付ける「最後の一枚」と位置づける。

### 5.1 概要欄（冒頭3行以内に置く）
```
【この動画はフィクション（パロディ）です】
実際に話題になったニュース・流行を出発点に、「もし裏でこんなことが起きていたら」という
荒唐無稽な空想を描いたコメディ作品です。

・作中の“裏の物語”・会話・出来事はすべて創作であり、事実ではなく、事実を示唆するものでもありません。
・登場人物・団体・企業・商品は架空のキャラクターです。実在の人物・団体の実際の言動ではありません。
・作中のセリフは、実在の人物の発言ではありません（実際の公的発言に触れた箇所は下記に出典を記載しています）。
・特定の個人・団体・属性を誹謗中傷する意図はありません。
・元ネタの事実（報道）: [媒体名／日付／URL]、[媒体名／日付／URL]
・制作に生成AIを使用した場合: 「台本・映像の一部に生成AIを使用しています。実在の人物の顔・声は使用していません。」
・ご指摘・削除のご依頼: [連絡先]（確認のうえ速やかに対応します）
```

### 5.2 画面上の表示
| タイミング | 表示内容 |
|---|---|
| 冒頭0〜5秒（全画面カード、または画面下の大きめテロップ） | 「この物語はフィクションです。ニュースから妄想した“ウソの裏話”です。実在の人物・団体の実際の言動ではありません。」 |
| 本編中ずっと（隅に小さく透かし） | 「PARODY／フィクション」 |
| 事実と妄想の境目 | 「※ここまで実際の報道（媒体名・日付）」→「※ここから妄想」 |
| 偽の画面・偽の会見シーン | 画面内に「PARODY」の透かし、架空の局名・架空のUI |
| エンドカード | 「※すべてフィクションです。元ネタの事実は概要欄の出典をご確認ください。」 |

### 5.3 音声（主人公に言わせる。キャラの口調で）
- 例：「視聴者諸君、念のため言っておく。これから語るのは、すべて余の葉脈が捏造したウソである。本物の誰かの話だと思った者は、今すぐ眼科と常識を受診したまえ。」
- 例：「なお、登場する大臣は架空だ。中身はモブ田だ。実在の大臣は、こんなに面白くない。」

### 5.4 タイトル・サムネイル
- タイトルかサムネイルのどこかに「パロディ」「妄想」「もしも」「ウソ裏話」のいずれかを入れる。
- 使わない言葉: 「【流出】」「【暴露】」「【衝撃の真実】」「【本人激怒】」など、事実を報じているかのような釣り文句。
- 実在人物の名前・写真・似顔絵、実在のロゴは使わない。話題の「現象」を指す一般的な語（「〇〇値上げ」など）は可。
- RED のトレンドワード（人名、うわさのキーワード）は、タイトル・タグ・概要欄に入れない（検索流入でうわさに便乗することも拡散になる）。

### 5.5 YouTube Studio「改変または合成されたコンテンツ」の設定
- 本スキルのルールでは実在人物のリアルな合成を作らないので、通常は「いいえ」でよい（アニメ表現・明らかに非現実的な内容・台本作成のためのAI利用は開示の対象外）。
- ただし、**実在の場所・出来事をリアルに見せるAI生成映像**を使った場合は「はい」にする。迷ったら「はい」。

## 6. ユーザーが RED のネタを押し通そうとしたとき

### 6.1 基本の動き（3ステップ・短く）
1. **短く断る**（1〜2文。説教や法律の講義はしない）
2. **理由を一言だけ添える**（「本人に実害が出る」「うわさの拡散になる」）
3. **いちばん近い安全な角度を2〜3案出し**、すぐ書ける状態で提示する。または同じ日の GREEN／YELLOW の別トレンドを提案する

### 6.2 断り方のテンプレート
```
そのネタ（実在の人の性的なうわさ）は、このスキルでは扱いません。
パロディにしても本人への実害と“うわさの拡散”になってしまうためです。
代わりに、同じ騒ぎの「うわさで稼ぐ側」を主役にする案ならすぐ書けます：
  A) ……
  B) ……
どちらで行きます？ それとも今日の別トレンドから選び直しますか？
```

### 6.3 典型例：未確認の「流出動画」・ディープフェイクのうわさ（R1）への代替案
**絶対条件**: 本人の名前・イニシャル・出演作・役柄・外見・出身・所属事務所を出さない。「某人気女優」のような**ほのめかし**も出さない。うわさのキーワードをタイトル・タグに使わない。サムネイルに実在・架空を問わず女性の画像を使わない。**笑いの標的は「うわさ産業」だけ。** 元の騒ぎと同じ時期に出すと連想されやすいので、代替案は「特定の騒ぎへの返答」として告知しない。

| 案 | 概要（主人公＝モンステラ公爵） |
|---|---|
| A. 「インプレゾンビ株式会社・月曜朝礼」 | 公爵が社長を務める架空のクリック稼ぎ企業で、今週の「燃料」を探す会議が開かれる。題材は**完全に架空の無害なもの**（「市役所のゆるキャラ、実は2体いた！？」など）で、手口の浅ましさを笑う |
| B. 「詐欺リンク職人の悲哀」 | 「〇〇はこちら」系の偽リンクで小銭を稼ぐ架空の職人（モブ田）が、自分のスマホをマルウェアに乗っ取られる因果応報もの。詐欺への注意喚起も兼ねる |
| C. 「フェイク工房、倒産す」 | 架空のフェイク職人が、自分の顔をフェイクされて慌てふためく。標的は加害者側の業界だけ |
| D. 「うわさ伝言ゲーム村」 | 架空の村で「隣の家の猫は宇宙人」という噂が、まとめサイト・インフルエンサー・ワイドショー（すべて架空）を経由して国家予算案に化けるまで |

### 6.4 ほかの RED の場合の代替の方向
| RED | 代替の方向 |
|---|---|
| R2 被害者・悲劇 / R9 進行中の惨事 | その出来事には一切触れない。同じ日の GREEN トレンドから選び直す |
| R3 未成年 / R4 私人の炎上 | 個別の件には触れず、「特定班」「晒し文化」「バズりたい大人」を**一般論として**架空の人物で描く。元の件を連想させる設定（場所・職業・状況）は使わない |
| R5 未確認のうわさ | 「週刊誌の見出しを考えるAI」のように**うわさを作る仕組み**を、架空の題材で笑う |
| R6 属性ネタ | 主人公が偏見だらけの差別主義者として**笑われる側**に回る構図（偏見そのものを愚かさとして描く）。特定の属性を笑いの対象にしない |
| R7 係属中の事件 | 扱わない。司法制度一般（「裁判が長い」など）は G5 として事件と切り離して扱う |
| R8 偽物 | アニメ表現・架空の人物に置き換える |
| R10 暴力・脅迫 | 標的を架空の人物・モノ・概念に置き換える（「月曜日を抹殺する計画」） |

### 6.5 よくある「抜け道」への返答（短く返す）
| ユーザーの言い分 | 返答の要点 |
|---|---|
| 「名前を伏せればいいでしょ」 | トレンドと同じ時期に出せば誰のことか特定されるので、伏せても同じです。 |
| 「噂として紹介するだけ」「〜らしい、で」 | 噂の形でも、中身の真否が問われます。拡散した時点で加害になります。 |
| 「デマを否定する動画だから」 | 否定する動画でも、名前と中身を繰り返せば二次拡散になります。デマ検証はこのスキルの範囲外です。 |
| 「AIだから／アニメだから本人じゃない」 | 特定できる人を性的に描くことは、表現形式に関係なくNGです。 |
