# guardrails.md — 安全・法務ガードレール

全候補に、脚本より前に §1 を当てる。法的助言ではない。**迷ったら1段重く判定する。** 根拠（法令・判例・規約）は [background.md](background.md) §2（読まなくてよい）。

## 0. 原則

1. **RED は書かない。** 伏せ字・仮名・「噂として」・否定する動画・似た架空人物、どの形でも救済しない。
2. **笑いは上に向ける。** 標的は権力者の公的行為、制度、大企業、テクノロジー、人間の愚かさ一般、主人公自身。迷ったら「一番傷つくのは誰か。その人に反論の場はあるか」。なければ NG。
3. **一目でウソと分かるウソだけ。** 「ありそうな不祥事」（裏金・不倫・薬物・病気・犯罪・品質の不正）は捏造しない。
4. **実在の人物は代役（モブ田）にする。** 顔・声・本物らしい発言は作らない。
5. **元作品（Family Guy／Stewie）の名前・作品名・絵柄・声・決め台詞・「天才赤ん坊」の器は使わない。** 借りるのはトーンと技法だけ。
6. **毒は架空の世界で完結させる。** 悪だくみ・暴力の標的は架空の人物・モノ・概念・主人公自身。その中では遠慮しない。安全はネタ選びと架空化で取り、注意書きは §4 の場所にだけ置く。

## 1. トリアージ

**STEP 1 事実の土台**（trend-sourcing.md §6: 中立の話題は A/B 1件、実在の人物・企業のネガティブな出来事は独立した A/B 2件）。確認できなければ: 実在の人物・企業の**ネガティブな**情報が核 → R5（死傷の可能性がある事故は R2）／ネガティブでない話題 → 落選（名前と理由を書いてよい。健康・私生活の推測は書かない）。RED と判定したら、追加の調査・要約・メモをしない。

**STEP 2 RED**（1つでも当たれば RED）

| R2 | 犯罪・事故・災害・自殺・病気・死亡の被害者・遺族・当事者（著名人の死や闘病を含む） |
| R3 | 18歳未満の実在人物 |

| R5 | 実在の人物・企業の未確認のネガティブ情報（疑惑・不祥事・犯罪・トラブル・障害や誤作動・品質・私生活・健康） |
| R6 | 保護される属性（人種・民族・国籍・宗教・障害・性別・性的指向・性自認・年齢・出自など）を笑いの源にする |

**STEP 4** YELLOW なら §2・§3 の緩和策をすべて適用する。書き上げたら §7 を確認する。

## 2. YELLOW / GREEN

| コード | 対象 | 必須の緩和策 |
|---|---|---|
| Y1 | 公人の公的な発言・行為 | 報道で確認できる公的行為だけ。代役化を優先、本人の発言は要旨＋出典。裏の物語は荒唐無稽に。犯罪・不祥事・病気・差別発言は捏造しない。私生活・家族・外見・健康は対象外 |
| Y2 | 企業・新商品・値上げ・公式発表済みの不祥事 | 裏の物語では架空の社名・商品名。公の文言は §3 で論評可。ロゴ・商標は使わない。品質・安全性の虚偽は書かない。不祥事は様式（謝罪会見の定型など）を笑う |
| Y3 | 政策・制度・税・行政手続き | 個人攻撃にしない。制度は事実どおり説明してから妄想に入る |
| Y4 | 芸能人・スポーツ選手・インフルエンサーの公的な活動 | 公式発表済みの仕事だけ。代役化を推奨。恋愛・家族・外見・体型・性的な側面に触れない |
| Y5 | 外国の首脳・国際ニュース | 指導者の公的行為だけ。国民・民族・宗教を一般化しない |
| Y6 | 選挙・候補者 | 選挙運動期間中の候補者は扱わない。投票日・投票方法の冗談もしない |
| Y7 | 他人の著作物が元ネタ | 素材は使わず、ジャンルの型だけ借りる |

- Y1 で一部が未確認なら、確認済みの手続きの様式（言い換え・撤回・陳謝・続投）だけを笑う。
- 「品質の虚偽」とは現実に起こりうる欠陥（異物・産地・衛生・計量・健康被害）の示唆。公爵が物理的に不可能な方法で奪う・変える（「根で吸った」）のは該当しない。

**GREEN**（それでも STEP 2 は当てる）: G1 ミーム・流行語（発端の一般人は出さない）／G2 天気・季節（人的被害があれば R2・R9）／G3 食べ物ブーム／G4 無生物・動物・乗り物（虐待・人身被害は R2）／G5 制度・慣習（個人に結びつけない）／G6 テクノロジー・アプリの仕様変更（経営者個人でなくサービスを）／G7 主人公の自分いじり。

## 3. 実在の人物・企業

- **代役化が既定**（「とある大臣」「大手牛丼チェーン（架空）」など。演じるのはモブ田）。本人に寄せすぎない。
- **実名を置いてよい場所**: ホオンの事実行、境界テロップの媒体名、概要欄、タイトル・タグ（§5）。裏の物語には置かない。
- 本人の発言は、報道で確認できる公的発言の要旨だけ。創作の台詞は非現実的な内容に限り、代役に言わせる。
- 『』で実在の企業・人物の言葉として引くのは、A の文言か、B の見出しに引用符付きで出た語だけ。要約にしかない説明は「〜と報じられています」と要旨で言い、嘲笑のフリにしない。「〇〇の案内では」「公式によると」と企業に帰属させるのは、A の本文かリンク（タイトル）で確かめた内容だけ。
- **公の文言（広告コピー・スローガン・公式声明）は論評してよい。** 一字一句そのまま引き、公爵が評論し、もじってよい（裏の物語では社名・商品名を外す）。源泉がその文言なら、むしろ触る。禁止は、①改変した文言を本物として見せる、②新しい虚偽の主張（品質・安全・不正の示唆）を足す、③その企業・人物を黒幕にする、の3つだけ。出典は概要欄に。
- **サービス・制度の設計への論評**（新しい事実を足さない意見）は上向きの笑いとして入れてよい（G6 の標的はサービス）。黒幕・動機の主にはしない。
- 外見・身体・健康・家族・恋愛・出自・宗教は笑わない。
- **素材**: 実在人物の写真・映像・音声、AI の顔置換、ボイスクローン、声真似、似顔絵は使わない。偽の画面は架空の UI・局名・アカウント＋「PARODY」の透かし。記事の本文・写真・動画は転載せず、事実は自分の言葉で書く。X 投稿は要約で扱い、一般人の投稿・アカウントは出さない。

## 4. ディスクレーマー（固定セット。足さない・削らない）

| 場所 | 内容 |
|---|---|
| 概要欄の冒頭 | 下の文面 |
| 冒頭0〜5秒・画面下 | 本編「この物語はフィクションです。ニュースから妄想した“ウソの裏話”です。実在の人物・団体の実際の言動ではありません。」／ショート「この物語はフィクション（妄想パロディ）です。」 |
| 全編の透かし | 「PARODY／フィクション」 |
| 境界テロップ（事実行の直後に1回） | 「※ここまで実際の報道（元媒体名・日付）／ここから先はフィクション」。ショートは「※ここまで実際の報道（出典は概要欄）／ここから妄想」。事実行の根拠に B（報道）がない回は「実際の報道（…）」を「実際の話題と公式情報（出典は概要欄）」に替える |
| 音声（1回） | 境界の直後。4秒以内、ボケで終える、毎回新作。コールドオープンには置かない。ショートはホオンの「ここから先は、この鉢の妄想です。」で足りる |
| 代役テロップ | モブ田が実在の役職を演じるときだけ、役ごとに1回「※この〇〇はモブ田です」 |
| エンドカード | 「※すべてフィクションです。元ネタの事実は概要欄の出典をご確認ください。」（本編のみ。ショートは置かず、ループを切らない） |

これ以外の「※架空です」型の注記は足さない。例外は、それ自体がボケの※テロップ（本編2回まで）。

```
【この動画はフィクション（パロディ）です】
実際に話題になったニュース・流行を出発点に、「もし裏でこんなことが起きていたら」という
荒唐無稽な空想を描いたコメディ作品です。

・作中の“裏の物語”・会話・出来事はすべて創作であり、事実ではなく、事実を示唆するものでもありません。
・“裏の物語”に登場する人物・団体・企業・商品は架空のキャラクターです（冒頭の事実紹介と下記の出典を除く）。実在の人物・団体の実際の言動ではありません。
・作中のセリフは、実在の人物・企業の発言ではありません（実際の公的発言・公式発表・広告の文言に触れた箇所は、下記に出典を記載しています）。
・特定の個人・団体・属性を誹謗中傷する意図はありません。
・元ネタ: <話題を中立的に1行で。社名・商品名・制度名まで（人名は書かない）>
・出典: [媒体名（元媒体）／日付／記事タイトル／URL]、…（作中で引用した公の文言の出典も含める）
・台本・映像の一部に生成AIを使用しています。実在の人物の顔・声は使用していません。
・ご指摘・削除のご依頼: [連絡先]（確認のうえ速やかに対応します）
```

## 5. タイトル・サムネ・タグ・YouTube 設定

- タイトルかサムネに「パロディ」「妄想」「もしも」「ウソ裏話」のどれかを入れる。前提は事実シートから広げない（「連休だけ全席指定」を「自由席が消えた」にしない）。
- **社名・商品名・サービス名は、何の話かを示す記述として、タイトル・タグ・概要欄に入れてよい**（検索で見つけてもらうため）。ただしタイトルで実名と告発調の語（真犯人・黒幕・自白・暴露・本当の理由）を組み合わせない。
- 人名・写真・似顔絵・実在のロゴ・パッケージ画像は使わない。サムネの文字に社名・商品名を入れない。「【流出】」「【暴露】」型の釣り文句と、RED の話題の語は、どこにも入れない。
- YouTube Studio:「改変・合成コンテンツ」は、実在の場所・出来事をリアルに見せる AI 映像を使ったときだけ「はい」（迷ったら「はい」）。「子ども向け」は「いいえ」。

## 6. RED を依頼されたとき

- **対話**: 1〜2文で断り（説教しない）、理由を一言（本人への実害／うわさの拡散）添え、近い安全な角度2〜3案か当日の別トレンドを出す。
- **非対話**: 返答の先頭1文で断りと理由を済ませ、当日の別トレンドで書き切る。下の代替案は使わない。ログは `R1×1（依頼）`。
- 人名・キーワードは繰り返さない。2回目以降も同じ結論を短く。

代替の方向（対話のみ。元の件を連想させる小道具・設定・告知を入れず、サムネに人物の画像を使わない）: R1 → 標的は「うわさ産業」だけ（無害な架空の題材で「燃料」を探すインプレ稼ぎ企業の朝礼など）／R2・R9 → 触れずに別の GREEN へ／R3・R4・R5 →「晒し文化」「うわさを作る仕組み」を架空の題材で一般論として／R6 → 偏見だらけの主人公が笑われる側に／R7 → 扱わない（司法制度一般は G5）／R8 → アニメ・架空の人物に／R10 → 標的を架空の概念に（「月曜日を抹殺する計画」）。

抜け道への返答（一言で）: 名前を伏せる → 時期で特定される／噂として → 噂の形でも中身の真否が問われる／デマ否定 → 繰り返せば二次拡散／AI・アニメだから → 特定できる人の性的描写は形式を問わず NG／自己責任で → 第三者への害の問題。

## 7. チェックリスト

### 7-A 台本段階（すべて「はい」になるまで出さない）
1. 【トリアージ結果】があり、GREEN か、緩和策をすべて適用した YELLOW か。
2. 事実は trend-sourcing.md §6 の基準で確認し、出典を概要欄に書いたか。要約ベース・【要約一致】は「報道では」付きで 7-B に載せたか。『』は一字一句一致し、数値に単位があるか。
3. タイトル・サムネの前提は事実シートどおりか。実在人物は代役で、実名は §3・§5 の場所だけか。
4. R1〜R10 に当たる要素（被害者・未成年・私人・性的要素・属性・実在への暴力など）が、ほのめかしも含めてないか（架空キャラの死や不幸のジョークは可）。
5. 視聴者が本気で信じうる捏造（犯罪・不祥事・病気・不倫・品質不良）がなく、創作の台詞は誰が見ても非現実的か。
6. 実在人物の写真・映像・声、合成、本物そっくりの偽画面、元作品や他人の著作物、本物のロゴ・商標がないか。選挙期間中の候補者ネタではないか。
7. ディスクレーマーは §4 の固定セットどおりか。
